## 简介

AURORA Analyzer 是一款专为 Windows 平台设计的系统事件日志导出与智能诊断分析工具。它能够自动收集并导出十余种 Windows 事件日志，然后通过内置的知识图谱驱动的诊断引擎对日志进行深度分析，将看似毫无关联的事件串联成完整的因果关系链，最终告诉你"到底发生了什么"以及"如何修复"。

无论你是普通电脑使用者还是专业系统管理员，AURORA Analyzer 都能为你提供强大而易用的诊断能力。

## 核心特性

### 智能诊断

- **知识图谱驱动** — 内置丰富的诊断规则库，支持事件 ID 匹配、严重程度评分（1-10 分）和因果关系分析
- **多维度扫描** — 系统文件完整性、服务状态、注册表健康度、磁盘 I/O、内存与 CPU、网络配置、事件日志
- **一键修复** — 诊断完成后自动执行修复，修复前自动创建系统还原点和快速备份快照
- **撤销管理** — 所有修复操作可撤销，支持精确回滚到操作前状态

### PRO 图形化模式

- **多格式日志导出** — CSV / JSON / XML / TXT 四种输出格式
- **趋势分析** — 时间序列趋势可视化，自动生成趋势数据
- **多日志源对比** — 同时分析系统日志、应用程序日志、安全日志等多源数据
- **交互式筛选** — 按事件级别、来源、时间范围灵活筛选

### 系统修复工具集

- SFC 增强修复、DISM 映像修复、磁盘错误修复、网络配置重置
- Windows 更新修复、存储感知优化、注册表修复、电源计划优化
- 自定义操作（命令白名单模式）
- 每次修复前自动创建系统还原点和快速备份快照

### 会话断点续传

- 诊断/修复进度自动持久化
- 意外中断后可从中断点恢复
- 显示中断天数帮助用户决策

### 安全机制

- **RSA-2048 签名验证** — 启动时自动验证所有核心模块文件完整性
- **运行时守护** — 持续监控调试器、逆向工具、内存篡改和代码注入
- **看门狗心跳** — 与外部看门狗进程保持通信
- **提权安全令牌** — UAC 提权场景下信任链的 AES-256-CBC 加密恢复
- **两阶段安全架构** — 安全模块自身通过加密签名的 CHK.ENC 文件验证
- **命令白名单** — 自定义修复模式消除代码注入风险

### 用户体验

- **现代化 GUI** — 动态星空背景、涟漪反馈、磁吸按钮、粒子进度条
- **中英双语** — 简体中文 / English 运行时动态切换
- **性能自适应** — 根据硬件配置自动选择极致/高性能/均衡/节能模式
- **断点续传** — 会话进度持久化，意外中断后可恢复

## 架构概览

AURORA Analyzer 采用模块化架构设计，代码库分为 9 个清晰的模块层：

```
Scripts/
├── Core/          ← 核心引擎层（动画引擎、共享工具、基础设施）
├── Security/      ← 安全模块层（RSA 验证、运行时守护、看门狗）
├── UI/
│   ├── Controls/  ← 控件库层（自定义 UI 控件、动画效果库）
│   └── Views/     ← 视图层（主界面、PRO 界面、启动画面、对话框）
├── Engines/       ← 智能引擎层（智能诊断引擎）
├── PRO/           ← 专业模式层（PRO 引擎与入口）
├── Session/       ← 会话管理层（进度持久化、撤销管理）
├── Repair/        ← 修复工具层（修复工具、修复日志、还原管理）
└── GUI/           ← 界面辅助层（GUI 辅助函数、语言资源）
```

各模块按需加载，单一职责，接口明确，支持独立维护和扩展。

## V1.3.26.7 更新亮点

V1.3.26.7 是一次以质量为核心的全面修复版本，共修复 53 个问题（18 项 Critical + 35 项 High）：

### 关键修复

- **完整性监控** — 从 FileSystemWatcher 事件订阅改为定时器轮询方案，修复过滤器不匹配导致监控完全失效的问题，增加 64KB 缓冲区和并发锁保护
- **注册表还原** — 修复 Start-Process 缺少 PassThru 参数导致注册表还原功能从未正常工作的问题
- **CleanSystem 修复** — 修复使用无效 cmdlet 导致系统清理功能完全失效的问题
- **代码注入防护** — 自定义修复模式从 Invoke-Expression 改为命令白名单映射表
- **PRO 参数传递** — 修复 PRO 引擎参数未从入口点传递导致用户选择全部被忽略的问题
- **函数签名冲突** — 修复 PRO 引擎与 CoreEngine 同名函数签名冲突，重命名并更新全部 11 处调用点
- **原子写入** — 从先删再移改为 File.Replace 实现真正原子替换，添加重试和备份机制
- **CSV 列错位** — Data 列从条件性改为始终存在，修复动态列导致的列错位
- **日志输出恢复** — 修复 Write-SmartLog 多余参数导致日志完全不输出的问题
- **健康等级本地化** — 硬编码中文改为从语言资源文件读取

### 安全增强

- SecurityModule 自身纳入完整性监控（两阶段架构 + CHK.ENC 签名验证）
- IO 异常从回退缓存改为安全失败模式
- 看门狗清理纳入异常退出路径
- 备份快照 ID 正确传递，撤销功能不再丢失备份信息

### 代码质量

- 消除 `return if (...)` 非法语法
- 修复 `$techData`、`$lightEvents`、`$dragAction` 等多处变量未定义问题
- 移除 `#requires -RunAsAdministrator` 改为运行时检查
- 消除函数重复定义
- CoreEngine 和 SecurityModule 在 PRO 入口点提前导入

## 快速开始

### 推荐方式

双击 `AURORA-Analyzer.exe`，程序自动完成安全验证和性能检测后进入主界面。

### 控制台方式

```powershell
.\Scripts\AURORA-AnalyzerLauncherGUI.ps1
```

### 指定语言

```powershell
.\Scripts\AURORA-AnalyzerLauncherGUI.ps1 -Language "en-US"
```

## 构建说明

使用项目根目录下的 `build.ps1` 脚本进行构建：

```powershell
.\build.ps1
```

构建脚本会执行以下操作：

- 注入版本号到所有 .ps1 文件
- 计算所有核心模块的 SHA-256 哈希值
- 生成 RSA 签名的 GAURORA.CHK.ENC 完整性校验数据库
- 使用 C# 编译器构建 AURORA-Analyzer.exe（含 CRC32 自校验）
- 内存安全清理（密钥变量归零）
