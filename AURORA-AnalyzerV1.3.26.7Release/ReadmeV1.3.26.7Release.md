## 核心功能

### 智能诊断模式

AURORA Analyzer 内置知识图谱驱动的智能诊断引擎，一次扫描即可覆盖以下维度：

- **系统文件完整性** — 基于 SFC/DISM 的增强型校验
- **服务状态分析** — 关键 Windows 服务运行状态与异常检测
- **注册表健康度** — 关键注册表键值完整性检查
- **磁盘空间与 I/O** — 空间使用率、碎片化、读写延迟评估
- **内存与 CPU 状态** — 实时资源占用与异常进程检测
- **网络配置** — DNS、IP、代理、防火墙规则健康检查
- **事件日志分析** — Windows 事件日志导出、聚合与趋势分析

诊断完成后，系统生成结构化报告，按严重程度（严重 / 警告 / 信息）分级展示，并提供一键修复入口。

### PRO 图形化模式

PRO 模式为高级用户与系统管理员提供专业级的可视化分析体验：

- **事件日志可视化导出** — 支持 CSV / JSON / XML 多格式导出
- **趋势分析图表** — 时间序列趋势分析，自动生成趋势数据
- **摘要报告** — 智能生成日志摘要与关键指标汇总
- **多日志源对比** — 同时分析系统日志、应用程序日志等多源数据
- **交互式筛选** — 按事件级别、来源、时间范围灵活筛选

### 系统修复工具集

内置丰富的系统修复工具，覆盖常见 Windows 问题场景：

| 修复工具 | 功能描述 | 撤销支持 |
|---------|---------|---------|
| SFC 增强修复 | 系统文件检查与修复，自动获取修复源 | ✅ 系统还原点 |
| DISM 映像修复 | Windows 映像组件存储修复 | ✅ 系统还原点 |
| 磁盘错误修复 | CHKDSK 增强，深度磁盘扫描 | ✅ 快照备份 |
| 网络配置重置 | 重置 TCP/IP、Winsock、DNS 缓存 | ✅ 配置快照 |
| Windows 更新修复 | 清除更新缓存，重置更新组件 | ✅ 服务状态快照 |
| 存储感知优化 | 清理临时文件、回收站、缩略图缓存 | ✅ 文件清单快照 |
| 注册表修复 | 关键注册表项校验与修复 | ✅ 注册表备份 |
| 电源计划优化 | 检测并修复电源配置异常 | ✅ 配置快照 |

**每次修复操作前，工具会自动创建保护点**，包括系统还原点（调用 Windows 系统保护）和快速备份快照（工具自维护）。如果修复后系统出现异常，可在工具内**一键撤销**。

### 会话断点续传

- 诊断/修复过程中如遇意外中断（断电、崩溃、误关闭），下次启动时会自动检测未完成的会话
- 提供会话恢复对话框，显示会话阶段、进度百分比和中断天数
- 可选择从断点继续或放弃会话重新开始
- 进度数据持久化存储，重启后不会丢失

## V1.3.26.7 更新亮点

### 概述

V1.3.26.7 是一次**以质量为核心的全面修复版本**。我们在 V1.3.26.6 完成的架构重构和质量基础建设之上，对全部核心模块进行了深度审查，修复了 53 个影响功能正确性、安全性和稳定性的问题，其中包括 18 项严重级别问题和 35 项高级别问题。

简单来说：**之前的版本功能已经完善，V1.3.26.7 让这些功能真正可靠地运行起来。**

---

### 1. 完整性监控全面修复

在之前版本中，文件完整性监控功能实际上从未正常工作过。原因是 .NET 的文件监视器不支持使用逗号分隔多个文件扩展名，导致没有任何文件能被监控到。V1.3.26.7 采用更可靠的定时器轮询方案替代了原有的事件监视方式，同时增加了 64KB 缓冲区和并发锁保护，确保高频率文件操作下监控的稳定性和准确性。

---

### 2. 注册表还原功能修复

之前版本中，注册表撤销操作存在一个关键缺陷——在执行注册表还原时，由于缺少一个必要的参数，程序无法获取还原操作的实际执行结果。这意味着注册表还原功能从未真正有效工作过。修复后，还原操作的结果现在能被正确获取和验证，注册表还原功能完全恢复正常。

---

### 3. 自定义修复安全加固

自定义修复模式之前存在代码注入风险——攻击者可以通过构造恶意命令执行任意代码。V1.3.26.7 引入了命令白名单机制，目前支持清空事件日志、重置网络栈、刷新 DNS、修复系统文件、清理临时文件和重置 Windows Store 等六个安全操作。白名单外的命令会被拒绝执行，从根本上消除了代码注入风险。

---

### 4. PRO 模式参数传递修复

之前版本中，用户在 GUI 界面选择的语言、日志类型、时间范围等设置没有被正确传递到 PRO 引擎内部，导致 PRO 模式始终使用默认值运行。这意味着用户的选择实际上被忽略了。修复后，所有用户设置都能正确传递到 PRO 引擎，语言切换、日志筛选等功能现在能按照用户的预期工作。

---

### 5. 健康等级文字多语言化

PRO 模式的健康评估功能中，"优秀"、"良好"、"一般"、"较差"等等级文字之前全部硬编码为中文。在英文模式下，用户仍然看到中文的健康等级文字。V1.3.26.7 将这些文字全部改为从语言资源文件中读取，切换中英文后，健康等级文字现在能正确跟随语言设置。

---

### 6. 日志输出恢复

之前版本中，智能引擎在运行过程中的日志输出因为一个参数错误而完全失效——用户在 GUI 界面看到的日志区域是空白的。修复后，所有诊断和修复过程的日志现在都能正常显示，用户可以实时了解程序的执行状态。

---

### 7. 会话数据安全加固

会话保存的"原子写入"机制之前存在数据丢失风险——如果在保存过程中程序意外崩溃，会话数据可能永久损坏。V1.3.26.7 改用了更可靠的原子替换方案，并添加了重试机制和备份后缀支持，确保会话数据在任何情况下都不会丢失。

---

### 8. 资源清理全面增强

之前版本中，如果程序因安全事件紧急退出，部分系统资源（如定时器、文件监控器、后台进程等）的清理代码会被跳过，可能导致资源泄漏。V1.3.26.7 在程序的退出路径中增加了完整的资源清理逻辑，确保无论程序以何种方式退出，所有资源都能被正确释放。

---

### 9. 多处运行时异常修复

修复了多处因变量未定义导致的运行时崩溃问题，包括：知识图谱缓存命中时崩溃、严格模式下变量未初始化报错、提权对话框拖动功能失效等。这些问题在特定场景下会导致程序异常退出，修复后程序运行更加稳定。

## 使用指南

### 启动工具

双击 `AURORA-Analyzer.exe`，工具自动完成安全完整性验证、硬件性能检测、显示启动画面并进入主界面。

### 智能诊断模式

1. 启动工具后，在主界面点击 **"智能诊断"** 按钮
2. 选择诊断范围（全系统扫描 / 仅系统文件 / 仅注册表 / 自定义）
3. 工具开始自动扫描，界面显示实时进度
4. 扫描内容包括系统文件完整性、服务状态、注册表健康度、磁盘 I/O、内存与 CPU、网络配置和事件日志
5. 扫描完成后，查看诊断报告：
   - 🔴 **严重问题** — 需立即处理
   - 🟡 **警告** — 建议处理
   - 🔵 **信息** — 仅供参考
6. 勾选要修复的项目，点击 **"一键修复"**
7. 工具自动创建保护点后执行修复

---

### PRO 图形化模式

PRO 模式专为高级用户和系统管理员设计：

1. 在主界面点击 **"PRO 图形化模式"**
2. 选择日志源：系统日志、应用程序日志、安全日志（需管理员权限）
3. 设置筛选条件：时间范围、事件级别、事件 ID 过滤、来源过滤
4. 点击 **"开始分析"**
5. 查看分析结果：摘要面板、趋势图、事件列表
6. 导出结果：CSV / JSON / XML / TXT 摘要

---

### 系统修复工具集

#### 执行修复

1. 在主界面选择 **"系统修复"**
2. 浏览可用修复工具列表
3. 选择需要的修复工具（可多选）
4. 点击 **"执行修复"**
5. 工具自动创建保护点（系统还原点 + 快速备份快照）
6. 等待修复完成
7. 查看修复结果报告

#### 撤销修复

如果修复后系统出现异常：

1. 打开工具，进入 **"修复历史"** 或 **"撤销管理"**
2. 找到要撤销的修复操作
3. 点击 **"撤销"**
4. 工具从保护点恢复系统状态
5. 完成后重启系统（如果需要）

1. 如果工具意外关闭（崩溃、断电、强制结束）

## 性能模式说明

工具根据您的硬件配置自动选择性能模式，您也可以手动调整：

| 模式 | 适用配置 | 特效等级 | 说明 |
|------|---------|---------|------|
| **极致** (Extreme) | 高端主机 (i7/R7+, 16GB+, 独显) | 全特效 | 完整星空背景、粒子效果、全帧率动画 |
| **高性能** (Performance) | 中高端 (i5/R5+, 8GB+) | 高特效 | 优化星空、部分粒子效果 |
| **均衡** (Balanced) | 中等配置 (i3/R3+, 6GB+) | 中特效 | 适中的视觉效果 |
| **节能** (Eco) | 低配主机 / 虚拟机 | 最小特效 | 减半帧率、无粒子效果、最低 CPU 占用 |

### 手动设置性能模式

设置环境变量 `AURORA_PERF_TIER`：

```powershell
# PowerShell 临时设置（仅当次会话）
$env:AURORA_PERF_TIER = "Eco"

# 永久设置（系统级）
[System.Environment]::SetEnvironmentVariable("AURORA_PERF_TIER", "Eco", "Machine")
```

可选值：`Eco` / `Balanced` / `Performance` / `Extreme`

## 安全机制

AURORA Analyzer 采用多层安全防护，确保工具不被篡改或恶意利用：

### 第一层：启动验证

启动时自动对所有核心模块文件进行 RSA-2048 签名验证，比对加密签名数据库中记录的哈希值。任何文件被修改、替换或损坏都会导致验证失败，工具拒绝启动。V1.3.26.7 还将安全模块自身纳入了完整性监控范围，进一步提升了安全链的可靠性。

### 第二层：运行时守护

工具运行时持续监控进程空间，检测常见调试器和逆向工具的附加行为，检测内存篡改和代码注入，与外部看门狗进程保持心跳通信。

### 第三层：操作安全

所有修复操作前自动创建保护点，包括系统还原点和快速备份快照。撤销管理器追踪所有修改，支持精确回滚。V1.3.26.7 增强了撤销功能中的备份信息关联，确保快照 ID 不会丢失。

### 第四层：提权安全

管理员提权过程中令牌严格隔离，提权完成后立即清理临时令牌。V1.3.26.7 还修复了自定义修复模式的代码注入漏洞，引入命令白名单机制。

## 常见问题 FAQ

### 启动与运行

<details>
<summary><b>Q: 工具启动后立即闪退？</b></summary>

**A:** 最常见的原因是安全验证失败。请检查：
- 使用的是否是官方构建的 EXE 文件
- 是否修改过 `Scripts/` 目录下的任何 `.ps1` 文件
- 是否关闭了调试器或逆向工具
- 杀毒软件是否误拦截了看门狗进程（可尝试添加信任）

如果问题持续，请查看构建日志中的错误详情。
</details>

<details>
<summary><b>Q: 启动时提示 "PowerShell 版本过低"？</b></summary>

**A:** 工具需要 PowerShell 5.1。请检查您的版本：

```powershell
$PSVersionTable.PSVersion
```

如果版本低于 5.1，请安装 Windows Management Framework 5.1。
</details>

<details>
<summary><b>Q: 从 V1.3.26.6 升级到 V1.3.26.7 需要做什么？</b></summary>

**A:** **直接替换全部文件即可。** 升级步骤：
1. 备份 `UserLogs/` 目录（如有历史日志需要保留）
2. 删除旧版本全部文件
3. 解压 V1.3.26.7 全部文件到相同目录
4. 如保留了旧日志，将其放回 `UserLogs/` 目录
5. 启动工具即可使用
</details>

</details>

### 系统修复

<details>
<summary><b>Q: 修复后系统出了问题怎么办？</b></summary>

**A:** 工具内置了完善的撤销机制：
1. 重新打开 AURORA Analyzer
2. 进入 **"修复历史"** 或 **"撤销管理"**

5. 工具从保护点恢复系统状态

如果无法启动工具，可以在安全模式下使用 Windows 自带的系统还原功能恢复到修复前的还原点。
</details>

### PRO 模式
