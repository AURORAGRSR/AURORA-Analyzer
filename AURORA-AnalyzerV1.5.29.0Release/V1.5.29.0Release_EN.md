# AURORA-Analyzer V1.5.29.0 Release Notes

***

## 1. Welcome to V1.5.29.0

Thank you for choosing AURORA-Analyzer! V1.5.29.0 is a special polish release focused on "visual immersion and interaction consistency". We have reshaped the starfield parallax into a multi-level depth system so every view switch shows a visible "forward穿梭 / backward归位" motion; unified the visual style of all dialogs so the global starfield flows through them; and fixed multiple animation, language switch, and quick-switch flashback issues.

## 2. More Immersive Starfield Parallax

### Multi-Level Depth Parallax Reshape

We found that the original starfield parallax had three "no-parallax" branches — Splash and MainForm were both at the deepest level, ProMode and SmartMode were at the same depth, and the depth difference between MainForm's two internal views was too small, making starfield changes almost invisible during these switches. V1.5.29.0 expands the original 4-level depth scheme into a 7-level depth mapping (0.00 ~ 1.00), forming a complete depth hierarchy from the splash screen (deepest) to the solution detail page (shallowest), so every view switch shows a visible starfield穿梭 or归位 motion.

The entire process does not increase the rendered star count — it only controls the global parallax intensity, so it brings more realistic depth perception while staying fluid. MainForm's depth is also dynamically determined by its internal view state, so the starfield lands on the correct level when returning to MainForm across views.

### Parallax Intensity Boost

To make depth differences more visually apparent, we adjusted the radial displacement coefficient from 0.18 to 0.28 and the transparency attenuation coefficient from 0.5 to 0.62, making the starfield穿梭 displacement amplitude and transparency changes more perceivable.

### Parallax Performance Optimization

We initially tried enabling glow and diffraction spikes for near stars during parallax to enhance visual feedback, but both costs scale linearly with star count, causing severe frame drops. V1.5.29.0 instead introduces a +50% alpha boost in the aurora layer as visual feedback — fixed cost, independent of star count — preserving the visual reinforcement during parallax without affecting performance. The boost uses smoothstep smoothing to avoid brightness discontinuity when parallax ends.

## 3. More Unified Dialog Visuals

### Global Starfield Flows Through Dialogs

V1.5.29.0 changes the backgrounds of 5 dialog windows (Elevation, Session Restore, Undo Viewer, Export History, Solution Detail) from the original opaque or translucent colors to fully transparent — not only visually transparent, but also non-participating in hit testing, so mouse events pass through directly to the shell starfield. This lets the global starfield flow through all dialogs, fully consistent with the visual style of Pro Mode, Smart Mode, and the Main Window, saying goodbye to the previous "isolated island" feeling of dialogs.

### Overlay Architecture Simplification

We removed the entire Overlay infrastructure — the IAuroraOverlay interface, PushOverlay/PopOverlay/RemoveOverlay methods, and the OverlayLayer Grid are all deleted. The main window now retains only the starfield and content container as child elements, making the architecture more concise.

***

## 4. Smoother Permission Flow

V1.5.29.0 relocates the permission selection (ElevationDialog) from inside the main window to after the Splash screen and before the main window. The permission flow is decoupled from the main flow: permission selection no longer occupies a main window view slot, the main window focuses on language selection and mode selection; the permission dialog participates in the starfield parallax depth chain as an independent view. Elevated processes skip the permission dialog and go directly to the main window; non-elevated processes see the permission selection after Splash, then enter the main window.

***

## 5. More Elegant Text Switching

### UWP Standard Transition Curves

The main window's right-side explanatory text switch animation now adopts UWP standard speed curves: the exit curve (0.7, 0, 0.3, 1) for natural deceleration, the entrance curve (0.1, 0.9, 0.2, 1) for fast-then-stable entrance. Exit duration 320ms, entrance duration 640ms, overshoot to 1.08 then settle to 1.0 with a soft S-curve, displacement ±52px — the overall rhythm is more elegant and closer to native UWP feel than before.

### Language Switch No Longer Shows Old Cache

Fixed the issue where the right-side explanatory text still showed old language cache during language switch. The root cause was the language switch notification sequence — the original sequence triggered the text binding updates after the switch animation started, causing the old language to still display during animation. V1.5.29.0 moves all 16 text binding notifications before the state change, ensuring text syncs immediately when switching languages. We also added cached instance language refresh for Pro Mode and Smart Mode, so even when views are reused from cache, the language syncs correctly.

***

## 6. More Robust Interaction Anti-Bounce

### Keyboard Focus Support

The main window's right-side explanatory text now responds to both mouse hover and keyboard Tab focus. We extracted the common hover logic so MouseEnter and GotFocus share the same handler — whether you move the mouse over a button or Tab to it via keyboard, the right-side explanation updates in sync.

### Unified Navigation Lock Eradicates Flashback

Fixed the persistent flashback issue when quickly switching between Smart Mode / Pro Mode / History View. The root cause was that each view used a local flag for anti-bounce, and some views had no anti-bounce, causing exit animation interruption and start value jumps. V1.5.29.0 establishes a unified navigation lock via the ViewManager.IsNavigating public property, and adds anti-reentry checks at 5 key navigation entry points — any new navigation request is rejected during exit animation playback, completely eliminating flashback.

### Smart Mode Status Text No Longer Flies Out

Fixed the issue where the Smart mode UWP status text was squeezed to the bottom-right corner and flew out. The status text position calculation now adds a retry mechanism (up to 25 times, 80ms interval, fully covering the 1000ms shell entrance animation), a layout completion check, and an X upper bound check, ensuring the text always lands in the correct position.
