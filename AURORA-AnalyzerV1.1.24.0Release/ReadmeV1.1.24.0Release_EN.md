## 7. System Repair — One-Click Fixes

When Smart Diagnostics finds a problem, or when you already know what needs fixing, the Repair Tools let you solve it with a single click.

### 6 Repair Types

| Repair | What It Does | When to Use |
|--------|-------------|-------------|
| **Disable Windows Update** | Pauses automatic updates | Updates are causing instability |
| **Enable Defender** | Re-enables Windows Defender | Defender was disabled by malware |
| **Disable Telemetry** | Stops diagnostic data collection | Privacy concerns |
| **Reset Network** | Resets TCP/IP, Winsock, DNS | Internet connection problems |
| **Clean System** | Clears temp files, event logs | Free up disk space, fresh start |
| **Custom** | Run your own repair command | Specific needs not covered above |

### Safe Repair Process — 5 Steps

Every repair follows this safety-first process:

```
Step 1: Pre-Check
  → Validates the repair is safe for your system
  → Checks if you have admin permissions

Step 2: Safety Net
  → Creates a System Restore Point (if enabled)
  → Creates a fast backup snapshot (always)
  → This means you can ALWAYS undo the repair

Step 3: Authorization
  → Shows you exactly what will change
  → You must confirm before anything happens

Step 4: Execute
  → Runs the repair command
  → Shows real-time progress
  → Verifies the result

Step 5: Verify
  → Checks that the repair worked
  → If it failed, auto-rollback begins
  → Logs everything to the audit trail
```

## 8. Undo System — Safe Repair with Rollback

Changed your mind? Something went wrong? No problem. The Undo System has two ways to reverse any repair.

### Protection Layer 1: System Restore Points

```
Before every major repair:
  → Windows creates a full system snapshot
  → This captures your entire system state
  → To undo: System Restore to the checkpoint
  → Note: Requires a reboot
```

**Best for:** Major system changes (disabling updates, network resets)

### Protection Layer 2: Fast Backup Snapshots

```
Before every repair:
  → Registry keys are exported as .reg files
  → Files are copied to a backup folder
  → Service configurations are saved as JSON
  → To undo: Instant restore, no reboot needed
```

**Best for:** Quick tweaks, registry changes, service modifications

### Viewing & Undoing Repairs

**Open Repair History:**
```
Dashboard → "Repair History" button
```

**What you'll see:**

| Column | Example | Meaning |
|--------|---------|---------|
| Date | 2026-05-25 14:32 | When the repair was done |
| Type | Enable Defender | What kind of repair |
| Target | Windows Defender Service | What was changed |
| Status | ✅ Success | Did it work? |
| Undo? | 🔄 Undoable | Can it be reversed? |

**Status Indicators:**
- ✅ **Success** — Repair completed perfectly
- ⚠️ **Partial** — Some parts worked, some didn't
- ❌ **Failed** — Repair couldn't complete
- ↩️ **Undone** — You've already reversed this

**To Undo a Repair:**
```
1. Open Repair History
2. Find the repair you want to undo
3. Click "Undo" button
4. Choose method:
   - "Fast Restore" (instant, no reboot)
   - "System Restore" (full rollback, needs reboot)
5. Confirm
6. Done! The repair is reversed.
```

### Complete Audit Trail

Every repair is recorded with full details:
- Session ID (unique identifier)
- Start and end timestamps
- Every command that was executed
- The restore point ID (if created)
- The backup snapshot location
- The final result

This means you have a complete history of everything AURORA Analyzer has done to your system — perfect for troubleshooting or compliance.

## 9. Bluescreen Analysis — Minidump Decoder

When Windows crashes with a Blue Screen of Death (BSOD), it saves a minidump file. AURORA Analyzer can read these files and tell you what went wrong.

### Supported BSOD Codes (20+)

Here are the most common bluescreen errors it can decode:

| BSOD Code | Name | Common Cause |
|-----------|------|-------------|
| `0x0000000A` | IRQL_NOT_LESS_OR_EQUAL | Bad driver or hardware |
| `0x0000001E` | KMODE_EXCEPTION_NOT_HANDLED | Driver bug |
| `0x0000003B` | SYSTEM_SERVICE_EXCEPTION | System file corruption |
| `0x0000007E` | SYSTEM_THREAD_EXCEPTION | Driver or antivirus conflict |
| `0x00000050` | PAGE_FAULT_IN_NONPAGED_AREA | Faulty RAM or driver |
| `0x000000D1` | DRIVER_IRQL_NOT_LESS_OR_EQUAL | Network driver issue |
| `0x00000109` | CRITICAL_STRUCTURE_CORRUPTION | Driver or malware |
| `0x00000116` | VIDEO_TDR_ERROR | Graphics card/driver failure |
| `0x00000124` | WHEA_UNCORRECTABLE_ERROR | Hardware failure (CPU/RAM) |
| `0x00000133` | DPC_WATCHDOG_VIOLATION | Driver or SSD firmware |

### How to Use Bluescreen Analysis

```
Dashboard → "Smart Diagnostics" →
  → Engine automatically finds .dmp files
  → Parses each dump file
  → Shows you:
      - BugCheck code and description
      - Crash parameters
      - Likely cause
      - Recommended fix
```

**Example Output:**
```
🔵 Bluescreen Detected: 2026-05-24 18:45
├── BugCheck: 0x00000116 (VIDEO_TDR_ERROR)
├── Parameter 1: 0xFFFFFA8012345678
├── Faulting Driver: nvlddmkm.sys
```

## 16. FAQ — Frequently Asked Questions

### Starting Up

**Q: "The EXE launcher won't open. What's wrong?"**

A: Possible causes:
- Your antivirus might be blocking it (add an exception for the folder)
- Missing .NET Framework 4.0+ (Windows Update will install it)
- Try right-clicking and selecting "Run as Administrator"

**Q: "Can I run the PS1 scripts directly?"**

A: No — and that's intentional for security. All scripts must be launched through the EXE. Direct execution will show "This script cannot be run directly!" and exit after 5 seconds.

**Q: "Why does the tool show a splash screen for a few seconds?"**

A: During startup, the tool is:
1. Verifying that none of its 19 core files have been tampered with
2. Performing a cryptographic security handshake
3. Initializing the graphics engine
This takes 1-3 seconds on most computers.

### Export & Diagnostics

**Q: "Security log export failed with an error."**

A: Security logs require administrator privileges. AURORA Analyzer will prompt you to elevate when needed. If you declined, restart the tool and accept the elevation prompt.

**Q: "Smart Diagnostics found no issues. Is my computer perfect?"**

A: Possibly! But also check:
- Make sure you selected the right time range (try expanding to 7 days)
- Check the Windows Reliability Monitor manually for a second opinion
- No news is usually good news — the tool only reports when rules match

**Q: "The export is taking a long time."**

A: Large date ranges (months of logs) can take longer. Typical times:
- 1 day: 5-20 seconds
- 1 week: 30-90 seconds
- 1 month: 2-5 minutes
- 6 months: 5-15 minutes
The progress bar shows real-time status. If interrupted, you can resume from the last checkpoint.

**Q: "What's the difference between System and Application logs?"**

A:
- **System logs**: OS-level events (drivers, services, hardware, crashes)
- **Application logs**: Software-level events (program crashes, installs, errors)
- **Security logs**: Security-related events (logins, permissions, audits)

For troubleshooting crashes and bluescreens, check System logs first.

### Repairs & Undo

**Q: "Is it safe to use the repair tools?"**

A: Yes! AURORA Analyzer always creates a backup before making changes. You can undo any repair at any time. The tool never makes changes without your explicit confirmation.

**Q: "I clicked 'Undo' but nothing changed."**

A: Try both undo methods:
1. **Fast Restore** — instant, no reboot needed (try this first)
2. **System Restore** — requires reboot but is more comprehensive
If neither works, your backup files may have been moved or deleted. Check `Scripts\SessionCache\backup\`.

**Q: "System Restore Point creation failed."**

A: Common causes:
- Not running as administrator → launch as admin
- System Restore is disabled → System Properties → System Protection → Enable
- Insufficient disk space → free up at least 5 GB

### Security

**Q: "Do I need an internet connection?"**

A: No! AURORA Analyzer works completely offline. All diagnostics, exports, and repairs run locally on your computer. No data is ever sent anywhere.

**Q: "Is my password or data sent to the developer?"**

A: Absolutely not. The tool has zero network connectivity. Your data stays on your computer. The password is used only for file integrity verification and is never transmitted.

**Q: "Can I run this on a corporate/enterprise machine?"**

A: Yes, but check with your IT department first. Some features require administrator privileges, which may be restricted by corporate policy. The repair audit trail makes it suitable for compliance environments.

---

### Interface

**Q: "The UI looks different on my old laptop."**

A: AURORA Analyzer automatically adapts its visual effects based on your hardware. On slower machines, it runs in "Eco" mode with fewer animations to keep the interface responsive. All features work the same — only visual effects are reduced.

**Q: "The text is in the wrong language."**

A: The tool auto-detects your Windows display language. If it's showing the wrong language, your Windows language settings may need adjustment. The tool follows your system's UI culture.
