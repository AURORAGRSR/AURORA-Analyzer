## 1. 版本概述

V1.6.31.0 是 AURORA-Analyzer 的**双主题版本**：视觉侧交付两套核心视觉系统（极光星空与玻璃材质）的形态学层面重做；安全侧完成启动信任链的全面审计与系统性加固。

### 1.1 设计基线

- **极光侧**：《AURORA 极光展现方式深度重构设计（V-B 幕帘化）》——由"极光太细了"的用户反馈触发，论证了旧"珠串 wisp"形态学为何调参无解，并给出"垂直条带幕帘"新形态学；
- **玻璃侧**：《AURORA 液态玻璃 V-LG1.7 实施交付报告》——V-LG1.1~V-LG1.7 七轮质感校准的收官波次，磨砂内核重写 + 白霜配方整包切换；
- **动效侧**：《AURORA UI/UX 动效系统全面复审报告》（2026-09-28）——总体评级 A-，确认三轨道解耦、配方化节奏、性能防线等既有体系，本轮星场改动均在既有时间基准与性能框架内落地；
- **安全侧**：启动信任链全链路审计（复审留档于内部文档，遵循负责任披露原则不在本文展开）。

### 1.2 本版本核心策略

- **换模型而非调参数**：极光从"椭圆珠串"换为"垂直丝缕幕帘"，玻璃从"深空蓝染色板"换为"冰白轻纱"——两者都是此前多轮调参无法突破的形态学瓶颈；
- **配方整包切换**：玻璃四参数（模糊/饱和/染色/白霜）相互支撑，整包生效而非单参数修补；
- **性能防线继承**：所有新视觉均在既有三档性能策略、30fps 玻璃采样节流、零分配热路径框架内实现；
- **安全加固自动化**：全部安全改进随构建管线自动生效，用户零配置。

### 1.3 兼容性约束

所有用户可见的命令行接口、环境变量、UI 交互、分析功能完全兼容；视觉系统随性能档位自动适配；用户偏好文件（`Wpf\user-preferences.txt`）可保留继续使用。

## 2. 全新极光星空：幕帘化极光与纵深星场

星域主引擎（`AuroraStarfield`，约 3400 行）在本周期完成形态学层面重做。旧极光的本质是"若干径向渐变椭圆沿水平正弦路径排布"——椭圆是各向同性衰减的胖椭圆，横向串起来无论怎么调半径、重叠、亮度，结果都只是"更亮的横向细带"。

### 2-1: 极光幕帘化（Column Curtain 形态学）

**变更**：每条幕帘由"N 根垂直条带（丝缕）+ 1 条底部光晕底座"组成，参照真实极光的物理结构重建：

- **垂坠形态**——丝缕沿"磁场线"方向垂直，底部 alpha 255 最亮、顶部 alpha 0 渐隐消散（非各向同性衰减）；
- **顶底异色**——新增 `TopHue` 字段实现垂直色梯度：顶部偏紫红（高空氧原子 630nm 红）、底部偏青绿（低空 558nm 绿），单根丝缕四段渐变 stops（顶 0 → 上中 80 → 下中 180 → 底 255）；
- **丝缕独立性**——每根条带独立相位偏移（`phase + i × 0.41`）+ 低频正弦扰动横向位置（频率 ≈0.012，±4-12px），"整幕齐摆"变为"参差起伏"；
- **中心浓两侧稀**——幕帘中央丝缕峰值 alpha 0.6、边缘 0.3，自然衰减出幕帘轮廓；
- **渲染成本**——单根条带为矩形 + 垂直渐变，成本约半颗旧 wisp 椭圆；渐变画刷整层预生成并 Freeze（5 条渐变 × 4 层 = 20 个），运行时仅更新透明度，热路径零分配。

**设计基线**：幕帘重构设计 §〇 诊断——"珠串 wisp 的形态学矛盾无法靠调参调和"；§一 新形态学五条视觉特征（垂坠/丝缕/顶底异色/独立摆动/光晕底座）全部落地。

**影响范围**：`Controls/AuroraStarfield.cs` `DrawCurtainColumns`（新增）、`DrawWispDiffusion`（旧路径提取保留供残晕层）、`AuroraLayerConfig`（+TopHue/IsColumnCurtain 字段）。

---

### 2-2: 四层幕帘纵深与动效语言

**变更**：

- **四层幕帘**——各层独立的 Y 位置、高度比例、色相、饱和度、振幅与速度，多层叠出纵深而非平面；
- **动效混合驱动**——呼吸 + 驻波脉动 + 色相游移 + 亮度呼吸四重叠加；流动方向随相位 ±1 切换，并叠加斜向丝缕流动——告别持续的水平横向移动；
- **层间暗部呼吸带**——亮暗对比构成"绚丽的载体"，层与层之间保留呼吸的暗部节奏。

**设计基线**：动效复审报告 §5.1"极光设计（用户偏好 ✓）"——"4 层幕帘独立配置、非持续从右向左水平横移"两条偏好确认达成。

**影响范围**：`Controls/AuroraStarfield.cs` AuroraLayerConfig 四层配置、幕帘 stops 更新逻辑。

### 2-3: 六级纵深视差与拖尾星场

**变更**：

- **视图切换纵深**——星体按 6 级深度映射，记录目标相位/起始相位/速度方向；近景/远景差异化运动 + 径向位移 + 差异化透明度；
- **纵深拖尾**——视差运动期间，近景星沿运动方向拉长为椭圆光条，EMA 平滑消除帧间隔抖动（如相机追焦的星轨效果）；
- **idle 深度呼吸**——静止状态保留极轻微的深度微振荡，画面"活着"而非静止贴图。

**设计基线**：动效复审报告 §5.1"纵深视差（用户偏好 ✓）"。

## 3. 全新玻璃材质：白霜液态玻璃

玻璃系统历经 V-LG1.1~V-LG1.7 七轮质感校准，本版本交付定稿的**白霜玻璃**配方——玻璃读作"比背景亮一层冰白轻纱"，而非旧的深空蓝染色板。多轮校准的核心教训：**单独调整任何参数都会被"其他支柱缺失"抵消**，故本轮以配方系统为单位整包切换。

### 3-1: 磨砂内核 v2（鬼影光环根治）

**变更**：旧 `AuroraBlurHlsl` 为固定权重 9-tap（w0=0.227/w1/w2 为 σ≈2.0 的常量），`blurRadius` 只放大采样步长而不重建权重——大半径下点扩散函数 = 锐利中心 + 同心鬼影光环。v2 重写：

- 双变体自适应——σ≤2 走 9-sample、σ>2 走 13-sample，按目标 σ 用双线性合并公式**重建权重**（离散权重 exp(-d²/2σ²)、相邻对合并质心、截断核归一化、σ 钳制 8.0）；
- σ 换算契约——`σ = blurRadius × 0.5`（锚定 CSS `blur(R)≈σ=R/2`）；
- 三档 σ = 3.0/4.0/5.0，全走 13-sample；
- 新增 `AURORA_BLUR_BACKEND=RTB/Shader` 环境变量强制指定模糊后端（永久 QA 对照钩子）。

**设计基线**：VLG1.7 交付报告 §二 根因 #2（磨砂内核鬼影）——"σ=10 时 PSF = 22.7% 锐心 + 光环"。

**影响范围**：`Materials/Backends/AuroraBlurHlsl.cs`（Source9/Source13 双变体重写）、`Materials/Effects/AuroraBlurShaderEffect.cs`（ComputeLinearGaussian/SetKernel）、`Materials/Backends/D3DCompiler.cs`（双字节码缓存）、`Materials/Backends/ShaderEffectBackend.cs`、`Materials/AuroraMaterialPipeline.cs`（后端强制钩子）。

## 4. 安全性与稳定性增强

本版本对启动信任链（构建期 → 启动期 → 运行期 → 提权链）完成了一轮全面安全审计与系统性加固。遵循负责任披露原则，本节仅概述改进方向，不展开实现细节。

### 4-1: 完整性校验增强

**改进方向**：新增构建时生成的完整性校验组件（随发行包分发），运行时对全部核心文件——包括主程序与安全模块自身——进行启动期与运行期双重校验，校验不通过将阻止运行。全部改进随新构建自动生效。

---

### 4-2: 令牌机制升级

**改进方向**：启动令牌与提权令牌的抗重放、抗篡改能力全面提升。升级对用户完全透明（令牌本身短时效 + 一次性使用，无跨版本消费场景）。

---

### 4-3: 日志隐私改进

**改进方向**：守卫与令牌校验日志不再输出安装路径等环境敏感信息，可运维性不损失。

---

### 4-4: 构建流程加固

**改进方向**：构建管线新增多重产物校验闸门（含新增的编译与签名环节），任何校验环节失败即中止构建，杜绝不一致产物流出。本条仅影响构建流程，目标运行机无新增依赖。
