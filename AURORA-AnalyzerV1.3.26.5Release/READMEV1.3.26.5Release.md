## 核心功能

### 智能诊断模式

AURORA Analyzer 内置知识图谱驱动的智能诊断引擎，一次扫描即可覆盖以下维度：

- **系统文件完整性** — 基于 SFC/DISM 的增强型校验
- **服务状态分析** — 关键 Windows 服务运行状态与异常检测
- **注册表健康度** — 关键注册表键值完整性检查
- **磁盘空间与 I/O** — 空间使用率、碎片化、读写延迟评估
- **内存与 CPU 状态** — 实时资源占用与异常进程检测
- **网络配置** — DNS、IP、代理、防火墙规则健康检查
- **事件日志分析** — Windows 事件日志导出、聚合与趋势分析

诊断完成后，系统生成结构化报告，按严重程度（严重 / 警告 / 信息）分级展示，并提供一键修复入口。

### PRO 图形化模式

PRO 模式为高级用户与系统管理员提供专业级的可视化分析体验：

- **事件日志可视化导出** — 支持 CSV / JSON / XML 多格式导出
- **趋势分析图表** — 时间序列趋势分析，自动生成趋势数据
- **摘要报告** — 智能生成日志摘要与关键指标汇总
- **多日志源对比** — 同时分析系统日志、应用程序日志等多源数据
- **交互式筛选** — 按事件级别、来源、时间范围灵活筛选

### 系统修复工具集

内置丰富的系统修复工具，覆盖常见 Windows 问题场景：

| 修复工具 | 功能描述 | 撤销支持 |
|---------|---------|---------|
| SFC 增强修复 | 系统文件检查与修复，自动获取修复源 | ✅ 系统还原点 |
| DISM 映像修复 | Windows 映像组件存储修复 | ✅ 系统还原点 |
| 磁盘错误修复 | CHKDSK 增强，深度磁盘扫描 | ✅ 快照备份 |
| 网络配置重置 | 重置 TCP/IP、Winsock、DNS 缓存 | ✅ 配置快照 |
| Windows 更新修复 | 清除更新缓存，重置更新组件 | ✅ 服务状态快照 |
| 存储感知优化 | 清理临时文件、回收站、缩略图缓存 | ✅ 文件清单快照 |
| 注册表修复 | 关键注册表项校验与修复 | ✅ 注册表备份 |
| 电源计划优化 | 检测并修复电源配置异常 | ✅ 配置快照 |

**每次修复操作前，工具会自动创建保护点**，包括系统还原点（调用 Windows 系统保护）和快速备份快照（工具自维护）。如果修复后系统出现异常，可在工具内**一键撤销**。

### 会话断点续传

- 诊断/修复过程中如遇意外中断（断电、崩溃、误关闭），下次启动时会自动检测未完成的会话
- 提供会话恢复对话框，可选择从断点继续或放弃会话
- 进度数据持久化存储，重启后不会丢失

## V1.3.26.5 更新亮点

### 概述

V1.3.26.5 是一次**架构级重大更新**。我们将整个代码库从单一巨型脚本重构成了清晰、模块化的分层结构。这一变化虽然对最终用户不可直接可见，但它为工具带来了更好的可维护性、更快的启动速度、更低的 Bug 风险，以及更坚实的基础来支持未来的功能扩展。

简单来说：**之前是一栋大平层，现在是一栋有明确功能分区的现代化大厦。**

---

### 1. 完全架构解耦

#### 改造前的问题

在 V1.2.x 及更早版本中，核心业务逻辑、界面代码、安全验证、修复工具、诊断引擎全部堆砌在少量巨型脚本文件中。这导致：

- **维护困难** — 修改一个功能可能影响不相关的模块
- **调试困难** — 错误难以定位到具体模块
- **扩展困难** — 添加新功能需要理解全部代码
- **启动缓慢** — 加载不必要的代码拖慢启动速度
- **团队协作困难** — 多人修改同一文件容易产生冲突

#### 改造后的成果

V1.3.26.5 将代码库解耦为 **9 个清晰的模块层**，每个模块职责单一、接口明确：


### 3. 安全模块独立化

安全相关功能从主脚本中完全抽离，形成独立的 `AURORA-SecurityModule.ps1`：

- **RSA 签名验证** — 启动时自动验证所有核心模块的完整性签名
- **运行时守护** — 持续检测调试器、逆向工具、内存篡改
- **看门狗通信** — 与外部看门狗进程保持心跳，确保工具未被异常终止
- **提权令牌安全** — 修复了提权令牌泄露漏洞（详见 AURORA-SEC-2026-001）
- **文件完整性数据库** — 维护 `GAURORA.CHK.ENC` 校验数据库

安全模块独立后，安全审计和维护变得更加清晰，任何安全补丁只需修改这一个文件。

### 5. 智能引擎独立

智能诊断引擎 (`AURORA-SmartEngine.ps1`) 现在是一个完全独立的模块：

- 不再嵌入主启动脚本，按需加载
- 知识图谱驱动的规则匹配引擎
- 支持规则热更新（无需重启工具）

## 使用指南

### 启动工具

1. 安全完整性验证

#### 方式二：控制台启动

适用于开发者或脚本集成场景：

```powershell
# 标准启动
.\Scripts\AURORA-AnalyzerLauncherGUI.ps1

.\Scripts\AURORA-AnalyzerLauncherGUI.ps1 -Console

# 跳过启动画面

```

### 智能诊断模式

1. 启动工具后，在主界面点击 **"智能诊断"** 按钮
2. 选择诊断范围（全系统扫描 / 仅系统文件 / 仅注册表 / 自定义）
3. 工具开始自动扫描，界面显示实时进度
4. 扫描内容包括：
   - **系统文件完整性** — 校验关键系统文件是否被篡改或损坏
   - **服务状态** — 检查 Windows Update、防火墙、时间同步等关键服务
   - **注册表健康度** — 检测损坏的注册表项、无效的 COM 注册

   - **事件日志** — 分析近期错误和警告事件

   - 🔴 **严重问题** — 需立即处理
   - 🟡 **警告** — 建议处理
   - 🔵 **信息** — 仅供参考
6. 勾选要修复的项目，点击 **"一键修复"**
7. 工具自动创建保护点后执行修复

## 安全机制

AURORA Analyzer 采用多层安全防护，确保工具不被篡改或恶意利用：

### 第一层：启动验证

- 启动时自动对 **25 个核心模块文件** 进行 RSA-2048 签名验证
- 比对 `GAURORA.CHK.ENC` 校验数据库中记录的哈希值
- 任何文件被修改、替换或损坏都会导致验证失败，工具拒绝启动

### 第二层：运行时守护

- 工具运行时持续监控进程空间
- 检测常见调试器 (x64dbg, WinDbg, OllyDbg 等) 的附加行为
- 检测内存篡改和代码注入
- 与外部看门狗进程保持心跳通信

### 第三层：操作安全

- 所有修复操作前自动创建保护点
- 系统还原点（Windows 系统保护）
- 快速备份快照（工具自维护，独立于 Windows 系统保护）
- 撤销管理器追踪所有修改，支持精确回滚

### 第四层：提权安全 (V1.3.26.5 新增)

- 管理员提权过程中令牌严格隔离
- 提权完成后立即清理临时令牌
- 防止令牌泄露导致的权限提升攻击

## 常见问题 FAQ

### 启动与运行

<details>
<summary><b>Q: 工具启动后立即闪退？</b></summary>

**A:** 最常见的原因是安全验证失败。请检查：
- 使用的是否是官方构建的 EXE 文件
- 是否修改过 `Scripts/` 目录下的任何 `.ps1` 文件
- 是否关闭了调试器或逆向工具
- 杀毒软件是否误拦截了看门狗进程（可尝试添加信任）

如果问题持续，请在 `build.log` 中查看错误详情。
</details>

<details>
<summary><b>Q: 启动时提示 "PowerShell 版本过低"？</b></summary>

**A:** 工具需要 PowerShell 5.1。请检查您的版本：

```powershell
$PSVersionTable.PSVersion
```

如果版本低于 5.1，请安装 [Windows Management Framework 5.1](https://www.microsoft.com/en-us/download/details.aspx?id=54616)。
</details>

<details>
<summary><b>Q: 启动时提示 "需要管理员权限"？</b></summary>

**A:** 部分功能（如系统文件修复、安全日志查看）需要管理员权限。工具会自动弹出提权对话框引导您以管理员身份运行。如果您不需要这些功能，可以普通用户身份继续使用基础诊断功能。
</details>

### 智能诊断

<details>
<summary><b>Q: 智能诊断扫描很慢？</b></summary>

**A:** 全系统扫描时间取决于：
- 磁盘类型（SSD 约 2-5 分钟，HDD 约 5-15 分钟）
- 系统事件日志的大小
- 安装的软件数量

您可以缩小扫描范围来加快速度（如仅扫描系统文件）。
</details>

<details>
<summary><b>Q: 智能诊断报告说某文件损坏，但我手动检查没问题？</b></summary>

**A:** 工具使用增强型 SFC 检测，可能比 Windows 自带的 SFC 更敏感。如果确认文件无问题，可以选择忽略该告警。后续版本会持续优化检测准确度。
</details>

### 系统修复

<details>
<summary><b>Q: 修复后系统出了问题怎么办？</b></summary>

**A:** 不要慌！工具内置了完善的撤销机制：
1. 重新打开 AURORA Analyzer
2. 进入 **"修复历史"** 或 **"撤销管理"**
3. 找到出问题的修复操作
4. 点击 **"撤销"**
5. 工具从保护点恢复系统状态

如果无法启动工具，可以在安全模式下使用 Windows 自带的系统还原功能恢复到修复前的还原点。
</details>

<details>
<summary><b>Q: 撤销修复需要多久？</b></summary>

**A:** 大部分撤销操作在 1-3 分钟内完成。如果需要重启系统，工具会给出提示。
</details>

<details>
<summary><b>Q: 可以一次修复多个问题吗？</b></summary>

**A:** 可以。在智能诊断报告页面上，勾选所有需要修复的项目，点击"一键修复"即可。工具会依次处理，并为整个批次创建一个统一的保护点。
</details>

### PRO 模式

<details>
<summary><b>Q: PRO 模式和智能诊断有什么区别？</b></summary>

**A:** 
- **智能诊断** 是自动化诊断工具，分析系统健康并提供修复建议
- **PRO 模式** 是专业级事件日志分析工具，侧重数据可视化和导出

两者互补：智能诊断发现问题，PRO 模式深入分析日志根因。
</details>

<details>
<summary><b>Q: 导出的日志文件很大怎么办？</b></summary>

**A:** 可以：
- 缩小时间范围（如只导出最近 3 天）
- 过滤掉"信息"级别的事件，仅导出"错误"和"警告"
- 使用 CSV 格式（比 XML 更紧凑）
</details>
