## 1. Version Overview

V1.4.27.5 is a comprehensive upgrade release for the AURORA-Analyzer animation and material systems. This update covers three core areas:

1. **Window Scale Animation Unification**: Porting and unifying the starfield scale enter/exit animation — previously exclusive to SplashScreen — across all windows in the application
2. **V5 Glass Material Pipeline Optimization**: Blur backend fixes, material preset calibration, and refinement of 14 optical layers
3. **Jelly Elastic Animation System**: AuroraButton hover-exit jelly rebound, iOS bounce release, control staggered enter overshoot convergence

In terms of window scale animation, prior to this version, each window's parameters were inconsistent:

- SplashScreen: Enter 1.15→1.0, Exit 1.0→1.15 (scale-up departure)
- MainFormView: Enter 1.1→1.0, Exit 1.0→0.85 (scale-down departure)
- ProModeView: Enter 1.1→1.0, Exit 1.0→0.85 (scale-down departure)
- ElevationDialogView: Enter 1.08→1.0, Exit 1.0→0.85 (scale-down departure)
- SessionRestoreDialogView: No window-level animation at all
- PerformanceUpgradeDialogView: Enter 0.92→1.0 (scale-down style), Exit fade-out only

V1.4.27.5 unifies all windows to:

- **Enter**: 1.15→1.0 (scale-down convergence), with Opacity 0→1 fade-in
- **Exit**: 1.0→1.15 (scale-up departure), with Opacity 1→0 fade-out

The core visual metaphor of this animation language is "emerging from the cosmos, dissolving into the cosmos" — windows appear like stars scaling in from afar, and disappear like stars scaling out into the distance, perfectly echoing the app's starfield background theme.

## 2. Splash Starfield Scale Animation Reference

SplashScreen is the animation benchmark for this unification. Its starfield scale animation consists of the following elements:

### 2.1 Enter Animation

- **Initial State**: Window-level `RenderTransformOrigin="0.5,0.5"`, `ScaleTransform ScaleX="1.15" ScaleY="1.15"` in `TransformGroup`
- **Animation**: ScaleTransform animates from 1.15 to 1.0, while Opacity fades in from 0 to 1
- **Easing**: UwpExpoOutEase (EaseIn mode), presenting an exponential deceleration elegant convergence
- **Duration**: 400ms (dialogs) / 600ms (main windows, using AuroraCustomBackEase)
- **Starfield Lock**: `StarfieldBg.IsWindowAnimating = true` during animation, degraded rendering reduces performance overhead

### 2.2 Exit Animation

- **Initial State**: ScaleTransform already at 1.0
- **Animation**: ScaleTransform animates from 1.0 to 1.15 (scale up), while Opacity fades out from 1 to 0
- **Scale Easing**: QuadraticEase (EaseOut mode), fast start, gentle finish
- **Fade Easing**: CubicEase (EaseOut mode), synchronizing with scale for elegant dissipation
- **Duration**: 800ms
- **Starfield Lock**: `IsWindowAnimating = true` during exit

### 2.3 Key Design Principles

- **RenderTransform must be at Window level**: Not on RootGrid or other child elements. Placing it on a child element causes the animation code to fail to find the target transform, leaving the initial scale permanently un-recovered.
- **XAML preset initial scale**: ScaleTransform is preset to `ScaleX="1.15" ScaleY="1.15"` in XAML, avoiding first-frame render flicker.
- **Stop starfield on Closed**: Call `StarfieldBg.StopAnimation()` after window closes, preventing DispatcherTimer leaks.

## 4. Window Exit Animation Unification

V1.4.27.5 unifies all windows' exit scale to 1.0→1.15 (scale-up departure), replacing the previous 1.0→0.85 (scale-down departure) across all windows.

### 4.1 Exit Parameters

| Parameter | Value |
|-----------|-------|
| ScaleTransform | 1.0 → 1.15 |
| Opacity | 1 → 0 |
| Scale Easing | QuadraticEase (EaseOut) |
| Fade Easing | CubicEase (EaseOut) |
| Duration | 800ms |

### 4.2 Exit Flow

1. `IsHitTestVisible = false`, preventing repeated triggers during exit
2. `StarfieldBg.IsWindowAnimating = true`, locking starfield to degraded rendering
3. Launch ScaleTransform 1.0→1.15 + Opacity 1→0 parallel animations
4. Execute cleanup callback on completion (StopAnimation + Close + Shutdown)

### 4.3 Visual Metaphor

The design intent of using "scale-up departure" instead of "scale-down departure":

- **Scale-up departure** (1.0→1.15): The window flies toward the observer and dissipates, creating a sense of "flying into the distance" that echoes the starfield theme
- **Scale-down departure** (1.0→0.85): The window collapses toward the center, visually a "close" semantic, lacking the poetry of "dissipation"

After unifying to scale-up departure, all windows' exits present the unified visual language of "turning into starlight and fading away."

In terms of glass material, V1.4.27.5 systematically optimized the V5 material pipeline: fixed RtbBlurBackend's hardcoded blur radius and redundant throttling, increased ShaderEffectBackend's MaxShaderBlurRadius from 8 to 40 to avoid truncating high-blur presets; calibrated AuroraFluentGlass preset's BlurRadius from 12 to 8 (blur doubling after backend fix was too strong), increased BlurSaturation from 1.0 to 1.4 (Mica vibrance +40%); refined all 14 optical layers (Body, Specular, Fresnel, Bevel, EdgeHighlight, Chromatic, Caustics, Iridescence, Refraction, InnerGlow, Tint, Glow, Noise, Shadow), adding CausticsLayer (caustics light spots) and IridescenceLayer (iridescent interference) as new optical enhancement layers.

In terms of jelly elastic animation, V1.4.27.5 introduced hover-exit jelly rebound (three-phase curve, ~271ms) and iOS bounce release feedback (two-phase, ~600ms) for AuroraButton, changed magnet snap from the old UwpDampedEase (3.5% overshoot) to pure EaseOutCubic (no overshoot); added V1.5 liquid glass overshoot convergence (1.07→1.0, 525ms QuarticEase) to control staggered enter and panel enter; added liquid glass micro-rebounds (1.0→1.03→1.0 enter, 1.0→0.97→1.15 exit) to window enter/exit. Also added 11 easing curve classes, building a complete UWP/iOS style easing curve library.

## 5. Starfield Background Locking Mechanism

V1.4.27.5 uniformly uses `IsWindowAnimating` to lock the starfield background during enter/exit animations across all windows.

### 5.1 Lock Timing

- **Enter**: Set `IsWindowAnimating = true` on window Loaded, unlock on animation completion
- **Exit**: Set `IsWindowAnimating = true` when exit animation starts, stop on window close

### 5.2 Lock Effect

When `IsWindowAnimating = true`, AuroraStarfield switches to degraded rendering mode:

- Reduces star count and draw frequency
- Skips breathing effects and meteor advanced effects
- Lowers GPU load, making window scale animations smoother

### 5.3 Unlock and Cleanup

- Set `IsWindowAnimating = false` in enter animation `Completed` event
- Call `StarfieldBg.StopAnimation()` in `Closed` event, stopping the DispatcherTimer
- Prevents memory leaks from timers continuing to refresh after window closes

## 10. Material Optical Layer Refinement

V1.4.27.5 refined parameters for all 14 optical layers. Final layer order: `Shadow(10)→Blur(20)→Tint(50)→Body(60)→Refraction(62)→InnerGlow(65)→Noise(70)→Caustics(75)→Fresnel(80)→Iridescence(85)→Specular(90)→Bevel(95)→EdgeHighlight(100)→Chromatic(105)→Glow(130)`.

### 10.1 BodyLayer (Base Layer)

- Color mixing changed from pure TintColor constant cold blue to **60% AmbientColor + 40% TintColor**, varying with environment color
- `depthFactor` 0.6→0.68, `bottomAlpha` coefficient 0.7→0.78 (V1.4.27.1 brightening)
- Bottom darkening coefficient 0.7→0.66, border alpha 35→45, directional border alpha 70→55
- Diagonal gradient (0,0)→(1,1), top-left bright→bottom-right dark

### 10.2 SpecularLayer (Specular Highlight Layer)

- Static directional light (0.28, 0.22) top-left quadrant + new secondary light spot (0.72, 0.78) bottom-right quadrant
- Primary light spot sin drift (DriftAmplitude=0.02, DriftSpeed=0.0008, ~8 second period)
- `SecondaryStrengthRatio=0.4`, `PeakAlphaCoeff=85`, `IsBreathing=true` continuous repaint
- Color 75% white + 25% AmbientColor

### 10.3 FresnelLayer (Fresnel Layer)

- Rewritten from single RadialGradientBrush to **4 LinearGradientBrushes** (top/bottom/left/right)
- Light-facing group (top/left) `BrightCoeff=150`, back-facing group (bottom/right) `DimCoeff=30`
- Bandwidth = 50% of short side, light-facing cool color, back-facing warm color (temperature shift)

### 10.4 BevelLayer (Bevel Layer)

- Order 100→95 (swapped with EdgeHighlight)
- Top depth pen from 2-segment→**4-segment white gradient** (peak 80→45→16→0)
- Bottom depth pen from 2-segment→**4-segment black gradient** (0→15→45→90)
- New top incident highlight band (height=bevelDepth×3.5, peak 130, mid 55)
- New bottom reflection band (height=bevelDepth×2.5, reflMid 28, reflPeak 45)

### 10.5 EdgeHighlightLayer (Edge Highlight Layer)

- Order 95→100 (swapped with Bevel)
- `BasePeakAlpha` 90→60, `BrightnessModulation` 80→40 (old peak 90-170 too strong, forming white edges)
- `GaussianSigma` 0.22→0.19 (sharper peak), highlight band width 2.0→2.2
- `IsFlowing` independent animation property for continuous 60fps repaint (not constrained by background sampling 30fps throttle)

### 10.6 Other Layer Optimizations

| Layer | Key Changes |
|-------|-------------|
| ChromaticLayer | Order 40→105 (moved above Body to avoid attenuation), PeakAlphaCoeff 40→80 |
| GlowLayer | peak 90→100, mid 0.4→0.5, rate 9.0→1.5 (ceremonial, 99% completion 0.5s→3.0s) |
| CausticsLayer | **V1.4.29 new**, Order=75, pre-generated 128×128 sin/cos interference texture, IsFlowing continuous displacement |
| IridescenceLayer | PeakAlphaCoeff 55→75 |
| RefractionLayer | Order 30→62 (moved above Body), peak 80→100, back-face 30→35 |
| InnerGlowLayer | peak 60→78→90, strength 0.20→0.30 |
| TintLayer | peak 25→30, low 5→7 (~20% brightening) |

## 12. AuroraButton Jelly Rebound

### 12.1 Hover-Exit Jelly Rebound (V1.5 Liquid Glass New)

When the mouse leaves the button, scale rebounds from 1.05 to 1.0 with jelly elastic convergence:

- **Trigger condition**: `_hoverProgress > 0.01 && !_hoverExitSpringActive`
- **Cancel logic**: Re-hover immediately cancels, magnet-snaps from current scale position
- **Total duration**: ~271ms (`_animSpeed * 0.23`)
- **Three-phase curve**:
  - **0→0.35 (fast drop)**: 1.05→0.96, EaseOutCubic `1-(1-t)³`, simulates inertia drop after magnet release
  - **0.35→0.65 (rebound)**: 0.96→1.02, EaseInOutQuad `t<0.5 ? 2t² : 1-(-2t+2)²/2`, simulates glass elastic recovery
  - **0.65→1.0 (convergence)**: 1.02→1.0, EaseOutQuart `1-(1-t)⁴`, graceful settling

### 12.2 iOS Bounce Release Feedback

Triggered by PreviewMouseUp / KeyUp(Enter/Space), 0→1 within 600ms:

- 0..0.5: 0.98→1.02 (EaseOutCubic first slight overshoot)
- 0.5..1.0: 1.02→1.0 (EaseOutQuad second convergence)
- Amplitude controlled within 2%

### 12.3 Magnet Snap Improvement

- **Old**: UwpDampedEase three-segment interpolation (3.5% overshoot), offset would cross center to opposite side
- **New**: Pure EaseOutCubic `1-(1-t)³`, no overshoot, no reverse offset, 500ms
- Magnet snap feels like "a light object naturally settling," better matching the soft quality of frosted glass

### 12.4 Other Button Animation Parameters (Unchanged)

- Hover scale: 1.0→1.05 (5%), press scale: 1.0→0.97 (3%)
- Magnet: radius 135, strength 0.35, max 17.5, smoothing 0.08
- Sheen: 2400ms, -0.6→1.6, EaseOutCubic, SkewTransform(-20°)
- Ripple: Lifetime 1.2s, Radius easeOutCubic, Alpha linear

## 14. Defect Fixes

### 14.1 ElevationDialogView Control Size Anomaly

**Issue**: ElevationDialogView's `RenderTransform` was placed on `RootGrid`, but the `OnLoaded` animation code operated on `this.RenderTransform` (Window level). The Window level had no RenderTransform, so the animation silently failed, and RootGrid's 1.10x scale was never recovered, causing all controls to appear 10% larger.

**Fix**: Moved `RenderTransform` and `ScaleTransform` from RootGrid to Window level, exactly matching SplashScreen's approach.

### 14.2 SessionRestoreDialogView C# 5 Compatibility

**Issue**: SessionRestoreDialogView.xaml.cs used C# 6's `?.` null-conditional operator, causing CS1525/CS1003 errors under the C# 5 compiler.

**Fix**: Replaced three instances of `x?.Method()` with C# 5-compatible `if (x != null) x.Method()` syntax.

### 14.3 Starfield DispatcherTimer Leak

**Issue**: Some dialog windows did not call `StarfieldBg.StopAnimation()` after closing, causing the starfield's DispatcherTimer to continue refreshing in the background, leading to memory leaks.

**Fix**: All windows' `Closed` events uniformly call `StarfieldBg.StopAnimation()`.

## 16. Known Limitations

### 16.1 Extended Exit Duration

Exit animation is extended from 450ms to 800ms, so windows will disappear slightly slower than before when the user clicks close. This is an intentional design — the longer exit duration gives the "turning into starlight and fading away" visual metaphor sufficient time to unfold.

### 16.2 Enter Starting Scale Amplitude

Enter starting scale is increased from 1.1 to 1.15, so windows will be larger than before when they first appear. On low-resolution screens, 1.15x scaling may briefly cause window edges to exceed screen boundaries. Since the animation is only 400-600ms and the scale center is at the window center, the actual visual impact is minimal.
