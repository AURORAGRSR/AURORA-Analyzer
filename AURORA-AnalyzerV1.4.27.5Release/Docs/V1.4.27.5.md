## 1. 版本概述

V1.4.27.5 是 AURORA-Analyzer 动效与材质系统的全面升级版本。本次更新涵盖三大核心领域：

1. **窗口缩放动效统一**：将 SplashScreen 独有的星空缩放入场/退场动效移植并统一到应用内的所有窗口
2. **V5 玻璃材质管线优化**：模糊后端修复、材质预设校准、14 层光学层逐层打磨
3. **果冻弹性动效系统**：AuroraButton hover 离开果冻回弹、iOS Q弹释放、控件交错入场过冲收敛

在窗口缩放动效方面，此前各窗口的参数参差不齐：

- SplashScreen：入场 1.15→1.0，退场 1.0→1.15（放大冲出）
- MainFormView：入场 1.1→1.0，退场 1.0→0.85（缩小消退）
- ProModeView：入场 1.1→1.0，退场 1.0→0.85（缩小消退）
- ElevationDialogView：入场 1.08→1.0，退场 1.0→0.85（缩小消退）
- SessionRestoreDialogView：无任何窗口级动效
- PerformanceUpgradeDialogView：入场 0.92→1.0（缩小式），退场仅淡出

V1.4.27.5 将所有窗口统一为：

- **入场**：1.15→1.0（放大收敛），伴随 Opacity 0→1 淡入
- **退场**：1.0→1.15（放大冲出），伴随 Opacity 1→0 淡出

这套动效语言的核心视觉隐喻是"从宇宙中浮现，向宇宙中消散"——窗口像星辰一样从远处放大显现，又像星辰一样放大消散于远方，与应用的星空背景主题完美呼应。

在玻璃材质方面，V1.4.27.5 对 V5 材质管线进行了系统性优化：修复了 RtbBlurBackend 的硬编码模糊半径和重复节流问题，将 ShaderEffectBackend 的 MaxShaderBlurRadius 从 8 提升至 40 以避免截断高模糊预设；将 AuroraFluentGlass 预设的 BlurRadius 从 12 校准至 8（修复后端后模糊量翻倍过强），BlurSaturation 从 1.0 提升至 1.4（Mica vibrance +40% 饱和度）；对 14 层光学层（Body、Specular、Fresnel、Bevel、EdgeHighlight、Chromatic、Caustics、Iridescence、Refraction、InnerGlow、Tint、Glow、Noise、Shadow）进行了逐层参数打磨，新增了 CausticsLayer（焦散光斑）和 IridescenceLayer（虹彩干涉）两个光学增强层。

在果冻弹性动效方面，V1.4.27.5 为 AuroraButton 引入了 hover 离开果冻回弹（三阶段曲线，~271ms）和 iOS Q弹释放反馈（两阶段，~600ms），将磁吸回弹从旧版 UwpDampedEase（3.5% 过冲）改为纯 EaseOutCubic（无过冲）；在控件交错入场和面板入场中加入了 V1.5 液态玻璃过冲收敛（1.07→1.0，525ms QuarticEase）；在窗口入场/退场中加入了液态玻璃微回弹（1.0→1.03→1.0 入场、1.0→0.97→1.15 退场）。同时新增了 11 个缓动曲线类，构建了完整的 UWP/iOS 风格缓动曲线库。

## 2. Splash 星空缩放动效参考

SplashScreen 是本次统一的动效基准。其星空缩放动效由以下要素构成：

### 2.1 入场动效

- **初始状态**：Window 级别 `RenderTransformOrigin="0.5,0.5"`，`TransformGroup` 中 `ScaleTransform ScaleX="1.15" ScaleY="1.15"`
- **动画**：ScaleTransform 从 1.15 动画至 1.0，同时 Opacity 从 0 淡入至 1
- **缓动**：UwpExpoOutEase（EaseIn 模式），呈现指数级减速的优雅收敛
- **时长**：400ms（对话框）/ 600ms（主窗口，使用 AuroraCustomBackEase）
- **星空锁定**：动画期间 `StarfieldBg.IsWindowAnimating = true`，降级渲染减少性能开销

### 2.2 退场动效

- **初始状态**：ScaleTransform 已在 1.0
- **动画**：ScaleTransform 从 1.0 动画至 1.15（放大），同时 Opacity 从 1 淡出至 0
- **缩放缓动**：QuadraticEase（EaseOut 模式），起步快、末段柔和
- **淡出缓动**：CubicEase（EaseOut 模式），与缩放同步优雅消退
- **时长**：800ms
- **星空锁定**：退场期间 `IsWindowAnimating = true`

### 2.3 关键设计原则

- **RenderTransform 必须在 Window 级别**：而非 RootGrid 或其他子元素。放在子元素上会导致动画代码找不到目标变换，初始缩放永不被收回。
- **XAML 预置初始缩放**：ScaleTransform 在 XAML 中预设 `ScaleX="1.15" ScaleY="1.15"`，避免首帧渲染闪烁。
- **Closed 事件停止星空**：窗口关闭后调用 `StarfieldBg.StopAnimation()`，防止 DispatcherTimer 泄漏。

## 4. 窗口退场动效统一

V1.4.27.5 将所有窗口的退场缩放统一为 1.0→1.15（放大冲出），取代之前各窗口的 1.0→0.85（缩小消退）。

### 4.1 退场参数

| 参数 | 值 |
|------|-----|
| ScaleTransform | 1.0 → 1.15 |
| Opacity | 1 → 0 |
| 缩放缓动 | QuadraticEase（EaseOut） |
| 淡出缓动 | CubicEase（EaseOut） |
| 时长 | 800ms |

### 4.2 退场流程

1. `IsHitTestVisible = false`，防止退场期间重复触发
2. `StarfieldBg.IsWindowAnimating = true`，锁定星空降级渲染
3. 启动 ScaleTransform 1.0→1.15 + Opacity 1→0 并行动画
4. 动画完成后执行收尾回调（StopAnimation + Close + Shutdown）

### 4.3 视觉隐喻

退场采用"放大冲出"而非"缩小消退"的设计意图：

- **放大冲出**（1.0→1.15）：窗口像星辰向观察者飞来后消散，有"飞向远方"的纵深感，与星空主题呼应
- **缩小消退**（1.0→0.85）：窗口向中心塌缩，视觉上是"关闭"的语义，缺乏"消散"的诗意

统一为放大冲出后，所有窗口的退场都呈现出"化为星光远去"的统一视觉语言。

## 5. 星空背景锁定机制

V1.4.27.5 在所有窗口的入场/退场动画期间统一使用 `IsWindowAnimating` 锁定星空背景。

### 5.1 锁定时机

- **入场**：窗口 Loaded 时设置 `IsWindowAnimating = true`，动画完成后解锁
- **退场**：退场动画开始时设置 `IsWindowAnimating = true`，窗口关闭时停止

### 5.2 锁定效果

`IsWindowAnimating = true` 时，AuroraStarfield 切换到降级渲染模式：

- 减少星星数量和绘制频率
- 跳过呼吸效果和流星等高级特效
- 降低 GPU 负载，让窗口缩放动画更流畅

### 5.3 解锁与清理

- 入场动画 `Completed` 事件中设置 `IsWindowAnimating = false`
- `Closed` 事件中调用 `StarfieldBg.StopAnimation()`，停止 DispatcherTimer
- 防止窗口关闭后定时器继续刷新导致的内存泄漏

## 9. V5 玻璃材质管线优化

V1.4.27.5 对 V5 材质管线进行了系统性优化，涵盖模糊后端修复、材质预设校准和管线架构改进。

### 9.1 RtbBlurBackend 修复

| 修复项 | 旧值 | 新值 | 说明 |
|--------|------|------|------|
| 硬编码模糊半径 | `CaptureBlurRadius=3.0` | 动态传入 blurRadius | 删除硬编码，使用实际 BlurRadius × CaptureScale 补偿 |
| 内部节流 | 33ms 重复节流 | 移除 | Pipeline 已通过 `BackgroundCaptureThrottleMs=33ms` 统一节流，RTB 内部重复节流导致最坏 ~66ms 延迟 |
| 渲染流水线 | 同步 4ms/帧 | 异步两阶段 | UI 线程截图（~1.5ms）+ 后台线程 Task.Run 模糊（~2.5ms），UI 线程 CPU 开销降至 1.5ms/帧 |
| 饱和度后处理 | 无 | BT.601 `ApplySaturation` | `gray = 0.299R + 0.587G + 0.114B`，与 ShaderEffectBackend 算法一致 |

### 9.2 ShaderEffectBackend 修复

| 修复项 | 旧值 | 新值 | 说明 |
|--------|------|------|------|
| MaxShaderBlurRadius | 8.0 | 40.0 | 避免截断高模糊预设（BlurRadius=12 → 12/0.5=24 被截断到 8） |
| 分辨率补偿 | 无 | `blurRadius / RenderScale` | 1/2 分辨率下模糊半径视觉放大 2×，需除以 RenderScale 补偿 |
| 饱和度接入 | 无 | HLSL BT.601 | 与 RtbBlurBackend 算法一致 |

### 9.3 AuroraMaterialPipeline 优化

- **共享捕获模糊半径**：取所有注册 Composer 的 `Preset.BlurRadius` 最大值作为共享捕获模糊半径（旧版硬编码 6.0）
- **共享饱和度**：取所有 Composer 的最大 `BlurSaturation` 作为共享饱和度
- **背景捕获节流**：`BackgroundCaptureThrottleMs = 33`（30fps），统一节流入口
- **后端选择**：优先 ShaderEffectBackend（HLSL PS 3.0），RtbBlurBackend 兜底；DwmAcrylicBackend 已移除

| FresnelStrength | — | 0.25 | 菲涅尔边缘光 |

## 10. 材质光学层逐层打磨

V1.4.27.5 对 14 层光学层进行了逐层参数打磨。最终层序为：`Shadow(10)→Blur(20)→Tint(50)→Body(60)→Refraction(62)→InnerGlow(65)→Noise(70)→Caustics(75)→Fresnel(80)→Iridescence(85)→Specular(90)→Bevel(95)→EdgeHighlight(100)→Chromatic(105)→Glow(130)`。

### 10.1 BodyLayer（基底层）

- 颜色混合从纯 TintColor 恒冷蓝改为 **60% AmbientColor + 40% TintColor**，随环境色变化
- `depthFactor` 0.6→0.68，`bottomAlpha` 系数 0.7→0.78（V1.4.27.1 提亮）
- 底部偏暗系数 0.7→0.66，边框 alpha 35→45，方向边框 alpha 70→55
- 对角线渐变 (0,0)→(1,1)，左上亮→右下暗

### 10.2 SpecularLayer（镜面高光层）

- 静态定向光源 (0.28, 0.22) 左上象限 + 新增次级光斑 (0.72, 0.78) 右下象限
- 主光斑 sin 漂移（DriftAmplitude=0.02, DriftSpeed=0.0008，约 8 秒一周期）
- `SecondaryStrengthRatio=0.4`，`PeakAlphaCoeff=85`，`IsBreathing=true` 持续重绘
- 颜色 75% 白 + 25% AmbientColor

### 10.3 FresnelLayer（菲涅尔层）

- 从单 RadialGradientBrush **重写为 4 个 LinearGradientBrush**（top/bottom/left/right）
- 朝光组(顶/左) `BrightCoeff=150`，背光组(底/右) `DimCoeff=30`
- 带宽 = 短边的 50%，朝光组冷色、背光组暖色（色温偏移）

### 10.4 BevelLayer（斜面层）

- Order 100→95（与 EdgeHighlight 交换）
- 顶部深度笔从 2 段→**4 段白渐变**（peak 80→45→16→0）
- 底部深度笔从 2 段→**4 段黑渐变**（0→15→45→90）
- 新增顶部入射高光带（高度=bevelDepth×3.5, peak 130, mid 55）
- 新增底部反射光带（高度=bevelDepth×2.5, reflMid 28, reflPeak 45）

### 10.5 EdgeHighlightLayer（边缘高光层）

- Order 95→100（与 Bevel 交换）
- `BasePeakAlpha` 90→60，`BrightnessModulation` 80→40（旧版峰值 90-170 过强形成白边）
- `GaussianSigma` 0.22→0.19（peak 更锐利），高光带宽度 2.0→2.2
- `IsFlowing` 独立动画属性持续 60fps 重绘（不受背景采样 30fps 节流制约）

### 10.6 其他层优化

| 层 | 关键变更 |
|----|----------|
| ChromaticLayer | Order 40→105（移到 Body 之上避免被衰减），PeakAlphaCoeff 40→80 |
| GlowLayer | peak 90→100, mid 0.4→0.5，rate 9.0→1.5（仪式感，99%完成 0.5s→3.0s） |

## 14. 缺陷修复

### 14.1 ElevationDialogView 控件大小异常

**问题**：ElevationDialogView 的 `RenderTransform` 被放在 `RootGrid` 上，但 `OnLoaded` 中的动画代码操作的是 `this.RenderTransform`（Window 级别）。Window 级别没有 RenderTransform，动画静默失败，RootGrid 的 1.10 倍缩放永不被收回，导致所有控件看起来被放大了 10%。

**修复**：将 `RenderTransform` 连同 `ScaleTransform` 从 RootGrid 移到 Window 级别，与 SplashScreen 的做法完全一致。

### 14.2 SessionRestoreDialogView C# 5 兼容性

**问题**：SessionRestoreDialogView.xaml.cs 中使用了 C# 6 的 `?.` 空条件运算符，在 C# 5 编译器下报错 CS1525/CS1003。

**修复**：将三处 `x?.Method()` 替换为 C# 5 兼容的 `if (x != null) x.Method()` 写法。

### 14.3 星空 DispatcherTimer 泄漏

**问题**：部分对话框窗口关闭后未调用 `StarfieldBg.StopAnimation()`，星空的 DispatcherTimer 继续在后台刷新，导致内存泄漏。

**修复**：所有窗口的 `Closed` 事件统一调用 `StarfieldBg.StopAnimation()`。

## 16. 已知限制

### 16.1 退场时长延长

退场动画从 450ms 延长至 800ms，用户点击关闭后窗口的消失速度会略慢于之前版本。这是有意为之的设计——更长的退场时长让"化为星光远去"的视觉隐喻有足够的时间展开。

### 16.2 入场起始缩放幅度

入场起始缩放从 1.1 提升至 1.15，窗口刚出现时会比之前更大。在低分辨率屏幕上，1.15 倍缩放可能导致窗口边缘短暂超出屏幕边界。由于动画仅 400-600ms 且缩放中心在窗口中心，实际视觉影响极小。
