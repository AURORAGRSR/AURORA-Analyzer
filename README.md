------

## 1. 欢迎使用 V1.6.31.0

感谢您选择 AURORA-Analyzer！V1.6.31.0 是一次视觉与安全双主题版本。视觉侧，我们完成了两套核心视觉系统——极光星空与玻璃材质——的**形态学层面重做**（不是调参，是换模型）：极光从"横向细带"进化为参照真实物理结构的**垂坠幕帘**，玻璃从深空蓝染色板进化为**白霜轻纱**，整个应用的视觉语言焕然一新。安全侧，我们对启动信任链完成了一轮全面审计与系统性加固——完整性校验、令牌机制、日志隐私全面升级，所有改进自动生效，无需您做任何配置。

本次更新围绕两个方向展开：**视觉系统焕新**、**安全性与稳定性增强**。

## 2. 全新的极光星空

### 告别"横向细带"，迎来真实极光的垂坠幕帘

如果您留意过旧版的极光，会发现它本质上是一串椭圆沿水平方向排开——无论怎么调整，看上去都是一条"横向细带"，缺少真实极光那种自上而下垂坠的丝缕感。V1.6.31.0 依照真实极光的物理结构彻底重建了极光形态：每条幕帘由**数十根垂直丝缕 + 底部光晕底座**组成，丝缕底部最亮、向上渐隐消散，就像高空气体沿着磁场线垂坠而下。

### 顶底异色，如真实大气发光

真实极光顶部偏紫红、底部偏青绿——不同高度的氧原子发出不同颜色的光。新极光为每根丝缕加入了**垂直色梯度**：顶部紫红渐变到底部青绿，一改旧版顶底同色的平面感。

### 丝缕参差起伏，多层纵深

每根丝缕有独立的摆动相位，幕帘不再是"整幕齐摆"的僵硬横移，而是参差起伏的活体；四层幕帘各自独立的高度、色相与速度叠出纵深。流动方向随呼吸正负切换，叠加斜向丝缕——极光第一次有了"深呼吸般的神秘感"。

### 星场纵深穿梭与星轨拖尾

切换视图时，星体按六级深度差异化运动，近景快远景慢，产生真实的纵深穿梭感；视差运动期间近景星沿运动方向拉长为光条——如同相机追焦时的星轨效果。静止时星场保留极轻微的深度呼吸，画面始终"活着"。

### 流畅度保障

动画速度与屏幕刷新率解耦（高刷屏不会"快进"）；新入场的星直接以静态出现，不产生性能尖峰。性能档位自动适配：Eco 档下星空动画与流星自动精简，Performance 档全开——无论什么机器，都保持流畅。

## 3. 全新的白霜玻璃

### 均匀奶油般的磨砂质感

旧版玻璃在大模糊半径下会出现"锐利中心 + 同心光环"的鬼影——磨砂内核经过重写，按目标模糊强度**重建采样权重**（小半径 9 采样、大半径 13 采样自适应切换），磨砂质感从"锐心+光环"变为均匀奶油。

### 从深空蓝到冰白轻纱

玻璃的配色语言整体切换为**白霜拟态**：模糊半径三档渐进提升至 12/16/20，叠加饱和度增强、冰白染色与亮度提升——玻璃读作"比背景亮一层冰白轻纱"，而不是旧版那种压暗的深蓝板。

### 有受光的立体边缘

玻璃边缘新增**内高光三件套**：全周细白线 + 顶缘柔光渐变 + 底缘暗线——玻璃有了"受光"的立体读法，不再是平面的染色膜。

### 全应用统一 + 星场光雾供养

控制台盒、任务 HUD、权限指示器、进度条、按钮——所有控件的玻璃全部对齐白霜语言，全应用质感统一。同时，星场新增两团缓慢呼吸漂移的深空光雾（青绿与冰蓝紫），让玻璃背后"有内容可透"——深空不再是 95% 的近黑，玻璃折射终于有东西可看。

## 4. 安全性与稳定性增强

本版本对启动信任链完成了一轮全面安全审计与系统性加固。遵循负责任披露原则，本节仅概述改进方向，不展开实现细节：

- **完整性校验增强**：新增构建时生成的完整性校验组件，运行时对全部核心文件进行启动期与运行期双重校验，校验不通过将阻止运行；
- **令牌机制升级**：启动与提权令牌的抗重放、抗篡改能力全面提升；
- **日志隐私改进**：日志不再输出安装路径等环境敏感信息；
- **构建流程加固**：构建管线新增多重产物校验闸门，任何环节失败即中止，杜绝不一致产物流出。

上述改进随新版本自动生效，对您的操作与分析功能完全透明。

## 5. 升级方式

本次更新包含新增的安全组件文件，请**整体替换旧版本目录**：

1. 备份您的用户偏好文件 `Wpf\user-preferences.txt`（如需保留个性化设置）；
2. 解压新发行包，整体替换旧版本目录；
3. 将备份的 `user-preferences.txt` 放回 `Wpf\` 目录；
4. 双击 `AURORA-Analyzer.exe` 启动。

**注意**：勿与旧版本文件混用或部分覆盖，也请勿删除发行包中的任何文件——混用或缺文件可能导致完整性校验阻止程序运行。

视觉系统随性能档位自动适配（Eco / Balanced / Performance / Extreme），无需任何配置；低端机自动降级。
