## 1. 版本概述

V1.4.27.1 是 AURORA-Analyzer 材质系统的深度打磨版本。本次更新的核心是将 V1.4.27.0 引入的四层扁平毛玻璃渲染系统（AuroraGlassMaterial）全面重构为 V5 九层独立分层架构，并对玻璃的边缘高光、取色层次、悬停过渡等视觉细节进行了反复调校。

V1.4.27.0 的 AuroraGlassMaterial 通过四层渲染管线（双层投影、真模糊背景、玻璃主体渐变、表层覆盖）实现了毛玻璃效果，这是从 WinForm GDI+ 无法实现模糊到 WPF GPU 加速模糊的跨越。然而在实际深度使用中，该系统暴露出多个视觉缺陷：玻璃内背景在特定条件下被拉伸变形、边缘出现硬圆环、悬停时高光只在四个角亮起、取色平淡无层次、噪点亮度每秒一次跳变、主界面玻璃在窗口切换后丢失模糊。

V1.4.27.1 通过以下策略解决了这些问题：

- **V5 九层独立渲染架构**：将四层耦合管线拆分为九个独立 IMaterialLayer 实现，每一层独立运算、按序叠加，通过 Order 属性排序。
- **IMaterialSurfaceHost 接口**：控件通过实现该接口接入 V5 管线，与渲染逻辑完全解耦。
- **AuroraMaterialComposer**：每个 V5 控件持有独立的材质合成器实例，调度九层渲染。
- **四种材质风格预设**：AuroraFluentGlass / LiquidGlass / Mica / Holographic，运行时可切换。
- **五级模糊后端回退链**：DwmAcrylic → ShaderEffect → RTB → D3D9Ex → Solid，根据系统能力自动选择。
- **EaseInOutCubic 仪式感过渡**：悬停高光以 3 秒的缓慢节奏优雅绽放，两端柔和减速。

尽管材质系统发生了重大重构，V1.4.27.1 保持了与 V1.4.27.0 的完全兼容。UseV5Pipeline 开关允许控件在 V5 管线和 V4 AuroraGlassMaterial 之间切换。所有命令行参数、环境变量、syncHash 通信协议和脚本接口均维持不变。

## 2. V5 材质管线架构

V5 材质管线采用四层分层架构（L1-L4），每一层有明确的职责边界。

### 2.1 L1 后端层（Blur Backend）

模糊后端层负责捕获控件后方的视觉内容并应用模糊处理。V1.4.27.1 实现了五级回退链：

| 后端 | 实现状态 | 说明 |
|------|----------|------|
| DwmAcrylicBackend | 已实现 | Win11 DWM Acrylic/Mica，需显式启用窗口背景 |
| ShaderEffectBackend | 已实现 | HLSL 着色器模糊（CPU 软件光栅化） |
| RtbBlurBackend | 已实现 | RenderTargetBitmap + BlurEffect |
| D3D9ExBackend | 预留 | Direct3D 9Ex 硬件模糊 |
| SolidFallbackBackend | 预留 | 纯色回退 |

后端选择逻辑通过 IsAvailable 接口检测平台能力。远程会话和虚拟机环境强制禁用 GPU 后端，回退到 RTB 软件模糊。DwmAcrylicBackend 增加了 _backdropApplied 标志，只有显式调用了 ApplyWindowBackdrop 启用 Mica 的窗口才会选中该后端。

### 2.2 L2 层层（Material Layers）

L2 层定义了九个独立的渲染层，每个层实现 IMaterialLayer 接口：

```csharp
public interface IMaterialLayer : IDisposable
{
    int Order { get; }
    string Name { get; }
    bool IsEnabled(MaterialRenderContext ctx);
    void Update(MaterialRenderContext ctx);
    void Render(DrawingContext dc, MaterialRenderContext ctx);
    void OnSizeChanged(Size newSize, double cornerRadius);
}
```

每个层通过 Order 属性确定渲染顺序，通过 IsEnabled 独立判断是否参与渲染，通过 Update 独立更新内部状态（如平滑过渡、动画进度），通过 Render 独立绘制到 DrawingContext。层间无耦合，所有参数通过 MaterialRenderContext 和 MaterialStylePreset 传递。

### 2.3 L3 合成器层（AuroraMaterialComposer）

AuroraMaterialComposer 是每个 V5 控件持有的材质合成器实例。它的核心职责：

- 在控件 Loaded 时向 AuroraMaterialPipeline 注册，Unloaded 时注销
- 在 OnRender 时调用 Render 方法，委托九层按序绘制
- 每帧调用 Update 方法，更新所有层的内部状态
- 计算 BackgroundSourceRect（控件在背景源坐标系中的矩形）
- 管理 HasActiveAnimation 状态，决定是否需要持续重绘
- 转发鼠标位置、尺寸变更等事件

Composer 持有 MaterialRenderContext 上下文对象，包含控件尺寸、圆角半径、鼠标位置、时间戳、DeltaMs、性能预设、环境色（顶/中/底三色）等所有渲染所需信息。

### 2.4 L4 控件层（Controls）

控件层实现 IMaterialSurfaceHost 接口接入 V5 管线：

```csharp
public interface IMaterialSurfaceHost
{
    double CornerRadius { get; }
    double Depth { get; }
}
```

控件在 OnRender 中调用 `_composer.Render(dc)` 委托渲染。UseV5Pipeline 开关控制是否走 V5 管线，false 时回退到 V4 AuroraGlassMaterial。

## 3. 九层渲染系统

V1.4.27.1 将玻璃渲染拆分为九个独立层，按 Order 依次渲染。

### 3.1 ShadowLayer（Order=10）

双层投影层。外层使用大半径柔光投影模拟玻璃材质的光晕扩散，内层使用小半径锐利投影增强玻璃边界的立体感。两层投影的颜色和透明度根据当前极光主题色动态调整。

### 3.2 BlurLayer（Order=20）

真模糊背景层。这是毛玻璃效果的核心。通过 AuroraMaterialPipeline 的共享背景采样获取控件后方的视觉内容，应用 GaussianBlurEffect 进行模糊处理。模糊半径通过性能预设控制（8-32 像素）。

BlurLayer 使用 CroppedBitmap 按 BackgroundSourceRect 裁剪背景采样，避免控件共享错误背景。当 BackgroundSourceRect 为空、背景不是 BitmapSource 或裁剪失败时，直接返回不绘制，避免拉伸变形。

### 3.3 TintLayer（Order=50）

环境色调染色层。V1.4.27.1 的关键改进：从单一采样点改为顶/中/底三点采样，使用 LinearGradientBrush 实现垂直方向渐变。4 段 GradientStop：顶边淡出 → 上中 peak(topColor) → 下中 peak(bottomColor) → 底边淡出，0.35→0.65 之间颜色自动线性插值，模拟极光从上到下的色相变化。

### 3.4 BodyLayer（Order=60）

玻璃主体层。绘制圆角矩形填充，叠加柔和边框。V1.4.27.1 将边框 alpha 从 80 降至 35，颜色从硬白色改为 tint+40，消除可见的硬白圆圈。

### 3.5 NoiseLayer（Order=70）

磨砂噪点层。V1.4.27.1 的关键修复：图集从亮度递增（128→177）改为每帧独立随机等亮度（固定 128），消除循环时的亮度骤降。帧切换从整数硬切改为连续帧位置 + blend 因子的交叉淡入淡出，消除每 125ms 的突兀跳变。

### 3.6 FresnelLayer（Order=80）

菲涅尔边缘反射层。V1.4.27.1 将半径从 0.5 提升至 0.62，过渡区从 15%（0.85→0.95→1.0）拓宽至 55%（0.45→0.72→0.9→1.0），peak alpha 从 180 降至 130，消除窄过渡区导致的硬椭圆环。

### 3.7 BevelLayer（Order=100）

斜角厚度感层。上亮下暗模拟立体边缘，缓存 Freeze 的 Brush 和 Pen 消除每帧分配。

### 3.8 ScanlineLayer（Order=120）

扫描线纹理层。仅 Holographic 风格启用，绘制水平扫描线模拟 CRT 显示器效果。

### 3.9 GlowLayer（Order=130）

悬停外发光层。V1.4.27.1 的核心视觉改进：

- **4 边均匀高光**：从单一 RadialGradientBrush（圆形等值线）改为 4 个 LinearGradientBrush，每个负责一条边向中心衰减，让等值线沿圆角矩形边缘均匀分布。
- **仪式感过渡**：引入 _glowProgress 进度变量（0..1）+ EaseInOutCubic 曲线映射，rate=1.5（约 3s 完成 99%），两端柔和减速。
- **零分配热路径**：4 个 brush 在 EnsureCache 创建，Render 仅更新 GradientStop.Color。

## 4. 材质风格预设

V1.4.27.1 通过 MaterialStylePreset 定义四种差异化材质风格：

### 4.1 AuroraFluentGlass（默认）

标准毛玻璃风格，全九层启用。模糊半径 12px，噪点动画速度 8fps，菲涅尔强度中等，悬停外发光强度中等。适用于大多数 UI 元素。

### 4.2 LiquidGlass

液态玻璃风格，更强的菲涅尔和高光。模糊半径 16px，菲涅尔 peak alpha 提升，外发光强度提升。适用于高亮交互元素。

### 4.3 Mica

Mica 风格，跳过 NoiseLayer（UseAnimatedNoise=false）和 BlurLayer（UseTrueBackdropSampling=true），启用 DWM Acrylic 后端。适用于窗口级背景。

### 4.4 Holographic

全息风格，启用 ScanlineLayer。模糊半径 20px，扫描线密度中等，菲涅尔强度最高。适用于科幻主题。

每种风格通过独立的参数预设控制各层的模糊半径、透明度、动画速度、发光强度等参数。

## 5. 模糊后端回退链

V1.4.27.1 实现了五级模糊后端回退链，根据系统能力自动选择最优后端。

### 5.1 DwmAcrylicBackend

Win11 DWM Acrylic/Mica 后端。设计为窗口级后端，需要先调用 ApplyWindowBackdrop(window) 启用 Win11 Mica/Acrylic，然后返回 null（让 DWM 系统合成器提供模糊）。

V1.4.27.1 的关键修复：增加 _backdropApplied 标志，IsAvailable 要求该标志为 true。未启用 Mica 时不被选中，避免 CaptureAndBlur 返回 null 导致模糊缺失。

### 5.2 ShaderEffectBackend

HLSL 着色器模糊后端。通过 D3DCompiler 编译 HLSL 高斯模糊着色器，应用于软件光栅化路径。明确标记为 CPU 软件光栅化实现，避免 GPU 加速误导。

### 5.3 RtbBlurBackend

RenderTargetBitmap + BlurEffect 后端。V1.4.27.0 的唯一后端，在 V1.4.27.1 中作为第三级回退。使用 1/2 分辨率（960×540 max）+ BlurRadius 2.5（等效 5）捕获模糊背景，30fps 节流。

### 5.4 远程会话/VM 环境处理

远程会话和虚拟机环境强制禁用 GPU 后端（DwmAcrylic 和 ShaderEffect），回退到 RTB 软件模糊，确保在无 GPU 加速的环境中也能正常工作。

## 7. 玻璃视觉调校

V1.4.27.1 对玻璃材质的视觉细节进行了深度调校。

### 7.1 边缘高光"四角亮"修复

V1.4.27.0 的 GlowLayer 使用单一 RadialGradientBrush（RadiusX=RadiusY=0.62），等值线是圆形。在圆角矩形内，圆形等值线只在四个角附近接近边缘：
- 四边中点归一化距离 ≈ 0.806 → 处于过渡区，alpha = mid
- 四角归一化距离 ≈ 1.14 → 超出 1.0，Pad 取 peak alpha

导致四角比四边中点亮。V1.4.27.1 改为 4 个 LinearGradientBrush，每个负责一条边向中心衰减（带宽 = 短边 40%），等值线变为"距离最近边缘的距离"，沿圆角矩形边缘均匀分布。

### 7.2 玻璃取色垂直渐变

V1.4.27.0 只采样控件顶部 Y 位置，整块玻璃用同一 AmbientColor。V1.4.27.1 采样顶/中/底三个 Y 位置（3 次反射调用 ≈ 0.003ms/帧），TintLayer 用 LinearGradientBrush 实现 4 段 GradientStop 垂直渐变。

### 7.3 边缘硬圆环修复

V1.4.27.0 的 BodyLayer 1px 白边（alpha=80）+ FresnelLayer 15% 窄过渡（peak=216）导致可见硬圆环。V1.4.27.1 将 BodyLayer alpha 降至 35、颜色改为 tint+40，FresnelLayer 过渡拓宽至 55%、peak 降至 130。

### 7.4 噪点亮度跳变修复

V1.4.27.0 的 8 帧图集亮度递增 + 硬切帧切换导致每秒一次亮度骤降。V1.4.27.1 改为等亮度独立随机生成 + 连续帧位置交叉淡入淡出。

### 7.5 极光取色加权混合

V1.4.27.0 的 SampleAuroraColorAt 离散层选择导致层切换瞬间颜色跳变。V1.4.27.1 改为全层加权 RGB 累加归一化，每层按 influence（raw²）加权，层间过渡平滑。

## 8. 悬停仪式感设计

V1.4.27.1 对悬停过渡进行了精心的仪式感设计。

### 8.1 EaseInOutCubic 缓动曲线

从纯指数平滑（rate=9.0，0.5s 完成）改为 EaseInOutCubic 曲线（rate=1.5，3s 完成 99%）：

```
eased = t < 0.5 ? 4*t*t*t : 1 - Math.Pow(-2*t + 2, 3) / 2
```

曲线特征：
- t=0.2 时 eased=0.032（仅 3.2% 强度，几乎察觉不到）
- t=0.5 时 eased=0.5（中点，线性推进）
- t=0.8 时 eased=0.968（96.8%，优雅收敛）
- 进入和离开对称，同样柔和

### 8.2 动画速度参数生效修复

V1.4.27.0 存在两个导致 rate 参数失效的缺陷：

1. **GlowLayer fallback**：DeltaMs<=0 时使用固定 smoothFactor=0.15（相当于 rate=9.0），绕过 rate 参数
2. **Composer 首帧 DeltaMs 瞬变**：_lastTimeMs=0 导致首帧 DeltaMs 为几百毫秒，smoothFactor≈1.0，跳过整个过渡

V1.4.27.1 的修复：
- fallback 也按 rate 计算（假设 60fps）
- DeltaMs 钳制到 100ms 上限

### 8.3 SpecularLayer 移除

V1.4.27.0 的 SpecularLayer 实现鼠标位置的白色高光跟随，但实际视觉效果不明显。V1.4.27.1 彻底移除该层（含文件、注册、HasActiveAnimation 分支），hover 反馈完全由 GlowLayer 承担，视觉表达更纯粹。

## 9. 缺陷修复

### 9.1 窗口切换时序竞争

V1.4.27.0 的 AuroraStarfield.Unloaded 无条件调用 ClearBackgroundSource()，在启动链 splash→权限窗口→mainformview→pro 中，旧窗口的 Unloaded 可能在新窗口 SetBackgroundSource 之后触发，错误清空新窗口已注册的背景源。

V1.4.27.1 的 ClearBackgroundSource 增加可选 source 参数，只有当前注册的背景源是自己时才清空。AuroraStarfield.Unloaded 传入 this。

### 9.2 DwmAcrylicBackend 误选

V1.4.27.0 的 IsAvailable 只探测平台能力，未检查是否已启用 Mica。未启用 Mica 的窗口选中该后端后，CaptureAndBlur 返回 null，BlurLayer 跳过渲染。

V1.4.27.1 增加 _backdropApplied 标志，未启用 Mica 时回退到 ShaderEffect 或 RTB。

### 9.3 BlurLayer 背景拉伸

V1.4.27.0 的退化路径将整张 starfield sample 以 Stretch=Fill 拉伸到 surface 矩形，导致宽高比变形。V1.4.27.1 在无有效 BackgroundSourceRect 时 return 不绘制，并在 Composer 中添加 TransformToVisual 失败的 PointToScreen + PointFromScreen fallback。

### 9.4 PRO 模式导出文件夹路径

V1.4.27.0 的 ShowUserLogs 使用 MyDocuments\AURORA\UserLogs，与 PowerShell 脚本的 $PSScriptRoot\..\..\UserLogs 不一致。V1.4.27.1 实现三级路径解析：ScriptsRoot 向上一级 + UserLogs → exe 目录上溯 6 级查找 → MyDocuments 兜底。

## 10. 性能优化

### 10.1 零分配热路径

所有渲染层实现零分配热路径。GlowLayer 的 4 个 brush 在 EnsureCache 创建，Render 仅更新 GradientStop.Color（值类型）。BodyLayer 和 BevelLayer 缓存 Freeze 的 Brush 和 Pen。NoiseLayer 的双 brush 在 EnsureCache 创建。

### 10.2 模糊背景 30fps 节流

模糊背景的 RenderTargetBitmap.Render 限制在 30fps（SharedBgUpdateMs=33），使用 1/2 分辨率（CaptureScale=0.5，960×540 max，BlurRadius=2.5）。

### 10.3 渲染订阅管理

CompositionTarget.Rendering 订阅在 Composer 数量归零时退订，防止空转消耗。AuroraStarfield 在 Loaded 事件重新订阅，防止 Tab 切换后动画停摆。

### 10.4 静态按钮跳过渲染

AuroraButton 对静态按钮（无 hover/press/ripple/spring/glare 且 disabledSettled）跳过 OnRender，避免不必要的重绘。

## 11. 兼容性说明

V1.4.27.1 在设计之初就将兼容性作为核心约束。

### 11.1 V4 回退兼容

UseV5Pipeline 开关允许控件在 V5 管线和 V4 AuroraGlassMaterial 之间切换。V5 控件的 OnRender 中保留 else 分支调用旧的 AuroraGlassMaterial 路径。

### 11.2 PowerShell 5.1 兼容

所有 C# 代码仍使用 C# 5.0 语言版本编译，确保在 PowerShell 5.1 的 CLR 4.0 环境中加载。

### 11.3 脚本接口兼容

所有命令行参数、环境变量、syncHash 通信协议和脚本接口均保持不变。PowerShell 脚本引擎无需任何修改。

## 12. 已知限制

### 12.1 ShaderEffectBackend 为 CPU 软件光栅化

ShaderEffectBackend 使用 RenderTargetBitmap.Render 走软件光栅化，性能可能不如 BlurEffect。已明确标记为 CPU 实现，避免 GPU 加速误导。

### 12.2 D3DCompiler P/Invoke 限制

D3DCompiler 的 P/Invoke 需要正确处理 UTF-8 编码和 64 位 SIZE_T，防止内存越界和截断。ID3DBlob.GetBufferSize 返回 64 位 SIZE_T，C# 声明需使用 long 类型。

### 12.3 Mica 后端依赖窗口级启用

DwmAcrylicBackend 是窗口级后端，需要先调用 ApplyWindowBackdrop 启用 Mica。未启用 Mica 的窗口会回退到 RTB 软件模糊，无法利用 DWM 原生 Acrylic 能力。
