## 1. 欢迎使用 AURORA Analyzer

**AURORA Analyzer** 是一款功能强大的 Windows 系统诊断与日志分析工具。它的核心使命是帮助您：

| 需求            | AURORA Analyzer 为您做什么                        |
| ------------- | -------------------------------------------- |
| 🔍 **排查系统问题** | 自动扫描系统日志，定位蓝屏、崩溃、卡顿的根本原因                     |
| 📊 **导出系统日志** | 将 Windows 事件日志导出为 CSV / JSON / XML 格式，方便分析   |
| 🔧 **一键修复**   | 自动修复 Windows Update 卡死、Defender 误报、网络异常等常见问题 |
| 📋 **健康报告**   | 生成详细的系统健康评估报告，包含趋势分析和建议                      |
| ↩️ **安全回滚**   | 修复前自动创建备份和系统还原点，确保随时可以撤销                     |
| 🛡️ **安全审计**  | 检查安全日志，发现暴力登录、权限提升等安全事件                      |

### 核心价值

- **不用打开事件查看器翻几千条日志了** — AURORA Analyzer 帮你自动筛选和分析
- **不用百度搜蓝屏代码了** — 自动解析 Minidump 文件，告诉你是哪个驱动导致的
- **修错了能反悔** — 每次修复都自动备份，一键撤销
- **导出进度不丢失** — 即使关闭程序，下次打开也能从中断处继续
- **银行级安全保护** — 从构建到运行全程加密验证，防篡改、防注入、防调试

## 2. 快速入门

### 2.1 系统要求

| 项目                 | 最低要求               | 推荐配置             |
| ------------------ | ------------------ | ---------------- |
| 操作系统           | Windows 10 1809+   | Windows 11       |
| 处理器             | 双核 1.5 GHz         | 四核 2.0 GHz+     |
| 内存               | 4 GB               | 8 GB+            |
| 磁盘空间           | 200 MB             | 500 MB+          |
| .NET Framework     | 4.x                | 4.8              |
| PowerShell         | 5.1+               | 5.1+             |

### 2.2 安装与启动

1. **解压** AURORA Analyzer 到任意目录（不建议放在系统盘或桌面）
2. **运行** `AURORA-Analyzer.exe`（由 build.ps1 构建生成）
3. 首次启动时，程序会自动进行**安全验证**：
   - 验证程序文件完整性（SHA256 哈希比对）
   - 检测是否有调试器附加
   - 检测是否有恶意 DLL 注入
4. 验证通过后，程序自动进入主界面

### 2.3 界面概览

AURORA Analyzer 主界面分为以下几个区域：

- **顶部工具栏**：语言切换、版本信息、退出按钮
- **左侧导航**：功能模块切换（日志导出、智能诊断、系统修复、撤销还原）
- **中央工作区**：当前功能模块的操作界面
- **底部状态栏**：性能等级、安全检查状态、运行时间

## 3. 日志导出功能

### 3.1 支持的日志类型

| 日志类型 | 说明 | 典型用途 |
|----------|------|----------|
| 系统日志 (System) | 操作系统核心事件 | 排查驱动错误、服务异常 |
| 应用程序日志 (Application) | 应用程序事件 | 排查软件崩溃、安装失败 |
| 安全日志 (Security) | 安全审计事件 | 审计登录记录、权限变更 |
| 安装日志 (Setup) | 软件安装/卸载事件 | 排查安装失败原因 |
| 转发事件 (ForwardedEvents) | 从其他计算机收集的事件 | 集中管理多台电脑日志 |

### 3.2 选择导出范围

- **按时间范围**：选择起始日期和结束日期
- **按事件级别**：筛选"严重"、"错误"、"警告"、"信息"
- **按事件 ID**：精确查找特定事件（如蓝屏事件 ID 1001）
- **按来源**：指定特定服务或驱动程序

### 3.3 高级筛选

在"高级筛选"中，您可以：

- 使用**关键词搜索**过滤日志内容
- 设置**最大导出条数**控制导出体积
- 选择**仅导出摘要**快速浏览

### 3.4 导出格式说明

| 格式 | 特点 | 推荐场景 |
|------|------|----------|
| CSV | 兼容 Excel，易于分析 | 自己分析或发给朋友 |
| JSON | 结构化数据，可编程处理 | 开发者、自动化工具 |
| XML | 完整的 Windows 事件格式 | 发给微软技术支持 |
| TXT | 纯文本，最简单 | 快速查看 |

### 3.5 查看导出结果

导出完成后，程序会自动打开导出文件夹，您可以：

- 双击 CSV 文件用 Excel 打开
- 用记事本查看 TXT 格式
- 用 JSON 查看器浏览结构化数据

## 4. 智能诊断功能

### 4.1 什么是智能诊断

智能诊断是 AURORA Analyzer 的核心功能。它会自动扫描 Windows 系统日志，使用内置的**知识库**（AURORA-TechData.json）匹配已知问题模式，然后给出诊断结论和修复建议。

### 4.2 五大诊断类别详解

| 类别 | 检查内容 | 常见问题 |
|------|----------|----------|
| **系统稳定性** | 系统崩溃、蓝屏、意外关机 | 驱动冲突、硬件故障、系统文件损坏 |
| **性能诊断** | 启动慢、响应卡顿、磁盘高占用 | 磁盘碎片、启动项过多、内存不足 |
| **网络诊断** | WiFi 断连、DNS 解析失败、网络受限 | 驱动问题、代理设置、防火墙规则 |
| **安全审计** | 暴力登录、权限提升、病毒扫描 | 系统被入侵、账户被盗、恶意软件 |
| **硬件诊断** | 磁盘错误、内存错误、过热 | 硬盘坏道、内存故障、散热不良 |

### 4.3 蓝屏问题分析

AURORA Analyzer 能够自动分析 Windows 蓝屏（BSOD）问题：

1. 自动定位 `C:\Windows\Minidump` 中的蓝屏转储文件
2. 解析蓝屏错误代码（如 `0x000000D1`、`0x0000001A`）
3. 识别导致蓝屏的驱动程序名称
4. 给出修复建议（更新驱动、检查硬件、系统修复）

### 4.4 解读诊断报告

诊断报告包含以下信息：

- **问题摘要**：用通俗语言描述问题
- **严重程度**：🔴严重 / 🟡警告 / 🔵信息
- **影响范围**：受影响的系统组件
- **修复建议**：具体的操作步骤
- **参考链接**：微软官方文档链接

## 5. 系统修复功能

### 5.1 支持的修复类型

| 修复类别 | 具体修复项 |
|----------|-----------|
| Windows Update | 重置更新组件、清除更新缓存、修复更新服务 |
| 网络修复 | 重置 TCP/IP 协议栈、清除 DNS 缓存、重置 Winsock |
| 系统文件 | 运行 SFC 扫描、DISM 修复、重建图标缓存 |
| 安全组件 | 修复 Windows Defender、重置防火墙规则 |
| 启动修复 | 修复启动配置、重建 BCD、修复引导记录 |

### 5.2 修复前保护机制

在执行任何修复前，AURORA Analyzer 会自动：

1. **创建系统还原点** — 可以回滚整个系统状态
2. **备份注册表项** — 保存即将修改的注册表值
3. **记录修复日志** — 详细记录每一步操作

### 5.3 如何执行修复

1. 在"系统修复"页面选择需要修复的类别
2. 勾选具体的修复项
3. 点击"开始修复"
4. 等待修复完成（某些修复需要重启电脑）

## 8. v1.2.24.5 新功能

### 8.1 安全架构全面升级

本版本对 AURORA Analyzer 的安全架构进行了**全面重构**：

**密钥体系升级**：
- RSA 公钥已轮换，所有令牌签名使用新的密钥对
- 会话密钥派生参数（SessionSalt）已更新
- 16 个核心脚本的 SHA256 完整性哈希已刷新

**这意味着什么**：旧版本 EXE 构建产物将无法通过新的安全验证，需要重新构建。这也意味着即使有人获得了旧版本的密钥，也无法影响到新版本。

**启动流程优化**：
- 修复了看门狗环境变量读取时机问题，消除了偶发启动失败
- 新增进程退出清理程序，确保程序退出时资源正确释放
- 启动时强制重置所有安全状态，防止残留状态干扰

### 8.2 启动稳定性提升

**修复了间歇性闪退问题**：

部分用户在启动 AURORA Analyzer 时会遇到程序闪退，然后下一次又能正常启动的问题。经过深入排查，发现根本原因是安全守卫在进行硬件断点检测时，内存访问偏移量计算错误，导致 Access Violation（访问违规）。

**修复内容**：
- 修正了 x64 系统下 CONTEXT 结构体中 ContextFlags 字段的写入偏移（从 0 更正为 0x30）
- 修正了 x64 系统下调试寄存器（Dr0-Dr3）的读取偏移（从 0x3E0 更正为 0x48）
- 修正了调试寄存器的读取大小（从 4 字节更正为 8 字节）
- 修复了 WOW64（32 位进程在 64 位系统上运行）下的内存分配问题

**修复效果**：程序启动成功率从 ~50% 提升至 100%，不再出现间歇性闪退。

### 8.3 安全防护增强

**新增诊断日志**：

安全守卫现在会生成详细的诊断日志，记录每一步安全检查的执行情况。日志文件位于 `%TEMP%\aurora_guard_diag.log`，方便排查问题。

**增强的进程退出保护**：

程序退出时，会自动清理以下资源：
- 看门狗命名管道连接
- 后台 Runspace 实例
- 安全检测定时器
- WMI 进程监控
- 所有 Aurora 相关环境变量

**EXE 构建优化**：
- 修复了 EXE 构建工具的进程终止异常处理
- 优化了管道服务器创建时序，消除了启动延迟
- 添加了 `AURORA_LAUNCHED_BY_EXE` 环境变量传递

## 9. 常见问题与场景

### 9.1 电脑频繁蓝屏怎么排查

1. 打开 AURORA Analyzer，进入"智能诊断" → "系统稳定性"
2. 点击"分析蓝屏问题"
3. 程序会自动定位 Minidump 文件并分析
4. 查看诊断报告，了解是哪个驱动导致的问题
5. 根据报告中的建议，更新驱动或检查硬件

### 9.2 系统变慢如何诊断

1. 进入"智能诊断" → "性能诊断"
2. 选择"全面性能分析"
3. 等待分析完成（约 2-5 分钟）
4. 查看报告中列出的性能瓶颈
5. 根据建议进行优化（清理启动项、扩展内存、优化磁盘）

### 9.3 怀疑电脑被入侵怎么检查

1. 进入"智能诊断" → "安全审计"
2. 选择"安全事件分析"
3. 程序会扫描安全日志中的异常登录、权限提升等事件
4. 查看是否有可疑的登录活动
5. 使用"导出日志"功能将安全日志保存下来，供进一步分析

### 9.4 导出日志给技术支持

1. 进入"日志导出"页面
2. 选择需要导出的日志类型（通常需要"系统"和"应用程序"）
3. 设置时间范围（建议选择问题发生前后各 24 小时）
4. 选择 CSV 格式导出
5. 将导出的文件发送给技术支持人员

## 12. 安全与隐私

**AURORA Analyzer 的安全承诺**：

- ✅ **本地运行**：所有数据在您的电脑上处理，不会上传到任何服务器
- ✅ **无网络通信**：程序不连接互联网，不需要任何网络权限
- ✅ **加密保护**：程序文件使用 RSA 签名验证，防止篡改
- ✅ **防注入**：运行时检测调试器和 DLL 注入
- ✅ **完整性验证**：每次启动时验证所有核心文件的 SHA256 哈希
- ✅ **看门狗机制**：EXE 和 PS1 之间存在双向心跳检测，任何一方异常都会触发保护

**修复操作的备份**：

- 修复前自动创建系统还原点
- 修复前自动备份注册表项
- 所有修复操作详细记录，可随时撤销
