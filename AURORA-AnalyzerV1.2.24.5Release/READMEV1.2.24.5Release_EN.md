## 1. Welcome to AURORA Analyzer

**AURORA Analyzer** is a powerful Windows system diagnostics and log analysis tool. Its core mission is to help you:

| Need            | What AURORA Analyzer Does                        |
| ------------- | -------------------------------------------- |
| 🔍 **Troubleshoot Issues** | Automatically scan system logs, identify root causes of BSODs, crashes, and slowdowns |
| 📊 **Export System Logs** | Export Windows Event Logs to CSV / JSON / XML for analysis |
| 🔧 **One-Click Repair** | Auto-fix Windows Update hangs, Defender false positives, network issues, and more |
| 📋 **Health Reports** | Generate detailed system health assessments with trend analysis and recommendations |
| ↩️ **Safe Rollback** | Auto-create backups and restore points before any repair |
| 🛡️ **Security Audit** | Check security logs for brute-force logins, privilege escalation, and other threats |

### Core Value

- **No more digging through thousands of Event Viewer entries** — AURORA Analyzer filters and analyzes them for you
- **No more googling BSOD codes** — Automatically parses Minidump files to identify the faulty driver
- **Repairs are reversible** — Every repair is auto-backed up; undo with one click
- **Progress never lost** — Even if you close the program, resume exactly where you left off
- **Bank-grade security** — End-to-end encrypted verification from build to runtime; tamper-proof, injection-proof, debug-proof

## 2. Quick Start

### 2.1 System Requirements

| Item                 | Minimum               | Recommended       |
| ------------------ | ------------------ | ---------------- |
| Operating System   | Windows 10 1809+   | Windows 11       |
| Processor          | Dual-core 1.5 GHz    | Quad-core 2.0 GHz+ |

### 2.2 Installation & Launch

1. **Extract** AURORA Analyzer to any directory (not recommended to place on the system drive or desktop)
2. **Run** `AURORA-Analyzer.exe` (generated by build.ps1)
3. On first launch, the program will automatically perform **security verification**:
   - Verify program file integrity (SHA256 hash comparison)
   - Detect if a debugger is attached
   - Detect malicious DLL injection
4. Once verification passes, the main interface appears

### 2.3 Interface Overview

AURORA Analyzer's main interface consists of:

- **Top Toolbar**: Language toggle, version info, exit button
- **Left Navigation**: Function module switching (Log Export, Diagnostics, Repair, Undo/Restore)
- **Central Workspace**: Operation interface for the current module
- **Bottom Status Bar**: Performance tier, security check status, uptime

## 4. Intelligent Diagnostics

### 4.1 What Is Intelligent Diagnostics

Intelligent Diagnostics is AURORA Analyzer's core feature. It automatically scans Windows system logs, uses a built-in **knowledge base** (AURORA-TechData.json) to match known issue patterns, then provides diagnostic conclusions and repair recommendations.

### 4.2 Five Diagnostic Categories

| Category | What It Checks | Common Issues |
|----------|----------------|---------------|
| **System Stability** | Crashes, BSODs, unexpected shutdowns | Driver conflicts, hardware failures, corrupted system files |
| **Performance** | Slow startups, lag, high disk usage | Disk fragmentation, too many startup items, insufficient memory |
| **Network** | WiFi drops, DNS failures, network restrictions | Driver issues, proxy settings, firewall rules |
| **Security Audit** | Brute-force logins, privilege escalation, virus scans | Compromised system, stolen accounts, malware |
| **Hardware** | Disk errors, memory errors, overheating | Bad sectors, memory faults, cooling issues |

### 4.3 Blue Screen Analysis

AURORA Analyzer can automatically analyze Windows Blue Screen (BSOD) issues:

1. Automatically locates Minidump files at `C:\Windows\Minidump`
2. Parses BSOD error codes (e.g., `0x000000D1`, `0x0000001A`)
3. Identifies the driver causing the crash
4. Provides repair recommendations (update driver, check hardware, system repair)

### 4.4 Reading Diagnostic Reports

Diagnostic reports include:

- **Issue Summary**: Plain-language problem description
- **Severity**: 🔴 Critical / 🟡 Warning / 🔵 Information
- **Impact Scope**: Affected system components
- **Repair Suggestions**: Concrete steps
- **Reference Links**: Microsoft official documentation

## 5. System Repair

### 5.1 Supported Repair Types

| Repair Category | Specific Repairs |
|-----------------|------------------|
| Windows Update | Reset update components, clear update cache, repair update service |
| Network Repair | Reset TCP/IP stack, clear DNS cache, reset Winsock |
| System Files | Run SFC scan, DISM repair, rebuild icon cache |
| Security Components | Repair Windows Defender, reset firewall rules |
| Boot Repair | Fix boot configuration, rebuild BCD, repair boot records |

### 5.2 Pre-Repair Protection

Before any repair, AURORA Analyzer automatically:

1. **Creates a system restore point** — Roll back the entire system state
2. **Backs up registry entries** — Save values about to be modified
3. **Logs all repair actions** — Detailed step-by-step records

### 5.3 How to Execute Repairs

1. On the "System Repair" page, select the repair category
2. Check the specific repair items
3. Click "Start Repair"
4. Wait for completion (some repairs require a reboot)

## 8. What's New in v1.2.24.5

### 8.1 Complete Security Architecture Overhaul

This version features a **comprehensive reconstruction** of AURORA Analyzer's security architecture:

**Key System Upgrade**:
- RSA public key has been rotated; all token signatures use new key pairs
- Session key derivation parameters (SessionSalt) have been updated
- SHA256 integrity hashes for all 16 core scripts have been refreshed

**What This Means**: Previous EXE builds will not pass the new security verification and must be rebuilt. It also means that even if the old key material was compromised, it cannot affect the new version.

**Launch Flow Optimization**:
- Fixed watchdog environment variable read timing, eliminating sporadic startup failures
- Added process exit cleanup handler for proper resource release
- Force-reset all security states at startup to prevent stale state interference

### 8.2 Launch Stability Improvements

**Fixed Intermittent Crash on Startup**:

Some users experienced crashes when launching AURORA Analyzer, only for it to work fine on the next attempt. Deep investigation revealed the root cause: the security guard's hardware breakpoint detection had incorrect memory access offset calculations, causing an Access Violation.

**Fixes Applied**:
- Corrected the ContextFlags field write offset in the CONTEXT structure for x64 systems (from 0 to 0x30)
- Corrected the debug register (Dr0-Dr3) read offset for x64 systems (from 0x3E0 to 0x48)
- Corrected the debug register read size (from 4 bytes to 8 bytes)
- Fixed memory allocation issues under WOW64 (32-bit processes on 64-bit systems)

**Result**: Program launch success rate improved from ~50% to 100%. No more intermittent crashes.

### 8.3 Enhanced Security Protection

**New Diagnostic Logging**:

The security guard now generates detailed diagnostic logs, recording the execution status of each security check step. The log file is located at `%TEMP%\aurora_guard_diag.log`, making troubleshooting much easier.

**Enhanced Process Exit Protection**:

On program exit, the following resources are automatically cleaned up:
- Watchdog named pipe connections
- Background Runspace instances
- Security detection timer
- WMI process monitor
- All Aurora-related environment variables

**EXE Build Optimizations**:
- Fixed exception handling for process termination in the EXE build tool
- Optimized pipe server creation timing, eliminating launch delays
- Added `AURORA_LAUNCHED_BY_EXE` environment variable propagation

## 9. FAQ & Common Scenarios

### 9.1 Frequent Blue Screens

1. Open AURORA Analyzer, go to "Intelligent Diagnostics" → "System Stability"
2. Click "Analyze Blue Screen Issues"
3. The program automatically locates and analyzes Minidump files
4. Read the diagnostic report to identify the problematic driver
5. Follow the recommendations: update driver or check hardware

### 9.2 System Slowing Down

1. Go to "Intelligent Diagnostics" → "Performance Diagnostics"
2. Select "Full Performance Analysis"
3. Wait for analysis (approx. 2-5 minutes)
4. Review identified performance bottlenecks
5. Optimize based on recommendations (clean startup items, expand memory, optimize disk)

### 9.3 Suspected Breach Check

1. Go to "Intelligent Diagnostics" → "Security Audit"
2. Select "Security Event Analysis"
3. The program scans for abnormal logins, privilege escalations, etc.
4. Check for suspicious login activity
5. Use "Export Logs" to save security logs for further analysis

### 9.4 Exporting Logs for Tech Support

1. Go to the "Log Export" page
2. Select the log types needed (typically "System" and "Application")
3. Set the time range (recommend ±24 hours around the issue)
4. Export in CSV format
5. Send the exported file to your technical support contact

## 12. Security & Privacy

**AURORA Analyzer's Security Commitment**:

- ✅ **Local Only**: All data is processed on your computer; nothing is uploaded anywhere
- ✅ **No Network**: The program does not connect to the internet; no network permissions needed
- ✅ **Encrypted Protection**: Program files are verified with RSA signatures to prevent tampering
- ✅ **Anti-Injection**: Runtime detection of debuggers and DLL injection
- ✅ **Integrity Verification**: SHA256 hash verification of all core files at every startup
- ✅ **Watchdog Mechanism**: Bidirectional heartbeat between EXE and PS1; either side detecting anomalies triggers protection

**Repair Operation Backups**:

- Auto-created system restore points before repairs
- Auto-backed-up registry entries before modifications
- All repair operations are logged in detail; any can be undone
