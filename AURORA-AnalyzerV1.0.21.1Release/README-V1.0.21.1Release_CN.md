# AURORA Analyzer v0.21.1 发行说明

> **让 Windows 系统事件日志不再晦涩难懂 —— 一键导出、智能诊断、自主修复**

***

## 欢迎使用 AURORA Analyzer

AURORA Analyzer 是一款专为 Windows 用户打造的系统健康诊断工具。它能够深入 Windows 的底层事件日志，自动找出那些可能导致蓝屏、卡顿、崩溃、网络异常的问题根源，并以清晰易懂的报告形式呈现出来。更强大的是，它内置了一套"自主修复引擎"，可以帮您一键执行经过验证的修复操作——无论是运行系统文件检查、清理磁盘，还是诊断驱动程序问题。

您不再需要去搜索一个个错误代码的含义，也不用去记忆 `sfc /scannow` 或 `DISM` 这些晦涩的命令。AURORA 会自动告诉您系统哪里出了问题、严重程度如何、应该怎么修，您只需点击确认即可。

***

## AURORA 能做什么

### 一键导出 Windows 事件日志

Windows 每天都在后台记录成千上万条事件日志，其中包含了系统运行的各种关键信息。但这些日志通常散落在不同位置，格式也难以阅读。AURORA 可以帮您：

- 一键导出 System（系统）、Application（应用程序）、Security（安全）等 8 种日志类型
- 支持按单日或自定义日期范围导出
- 自动筛选出高危事件（严重、错误、警告），无需在海量信息中大海捞针
- 输出格式包括 CSV 表格、JSON 结构化数据、XML 标准格式和 TXT 可读摘要报告

### 系统健康智能诊断

AURORA 内置了一个"智能诊断引擎"，它会像一位系统专家一样自动分析您的电脑状态：

- **自动检测系统运行时间**：判断您的电脑是刚开机、稳定运行中，还是近期发生过异常重启
- **智能识别时间窗口**：如果探测到近期蓝屏或意外关机，会自动缩小分析范围，精准定位崩溃前 2 小时的日志
- **Minidump 蓝屏转储探测**：主动检查系统中是否存在未分析的蓝屏内存转储文件
- **知识图谱碰撞匹配**：将提取到的事件与内置的 6 大类诊断规则库逐一比对，找出所有匹配的已知问题

### 自主修复引擎

这是 AURORA 最核心的能力。当诊断出系统问题后，它不会只告诉您"有问题"，而是会：

- 列出所有匹配到的问题，按严重程度从高到低排列
- 每个问题都附带详细的**原因分析**、**解决方案**和**可执行命令**
- 每条命令标注了**风险等级**（低 / 中 / 高），让您清楚地知道每个操作的安全性
- 需要管理员权限的命令会特别标注 \[Admin] 标签
- 高风险操作会弹出**全息授权弹窗**，需要您逐项确认后才执行
- 操作失败时支持**自动回滚**，最大程度保障系统安全

内置的诊断规则覆盖以下六个领域：

| 领域             | 典型问题举例                       |
| -------------- | ---------------------------- |
| **系统稳定性**      | 意外关机、蓝屏、程序崩溃、磁盘错误、启动缓慢       |
| **驱动与硬件**      | 显卡驱动超时、设备驱动未正确加载             |
| **网络与通信**      | DHCP 无法获取 IP、DNS 解析超时、网络资源耗尽 |
| **Windows 更新** | 更新安装失败                       |
| **安全与身份**      | 登录失败（支持暴力破解检测）               |
| **应用与服务**      | 打印后台处理程序错误                   |

### 趋势分析

除了单次诊断，AURORA 还支持对日志进行**趋势分析**。它会统计一段时间内各种错误事件的出现频率变化，帮助您判断：

- 某个问题是在恶化还是已经自行恢复
- 最近一次系统更新是否引入了新问题
- 硬件故障的早期征兆

### 断点续传 —— 再也不怕中途退出

导出大量日志可能需要一些时间。AURORA 内置了**会话持久化系统**，会自动保存当前任务的进度。如果因故中断（比如不小心关闭了窗口），下次启动时会检测到未完成的任务，询问您是否从断点继续。进度信息会保留 7 天，过期自动清理。

### 中英双语支持

AURORA 会根据您的 Windows 系统语言自动切换界面语言。中文用户看到的是完整的中文界面和中文报告，英文用户则看到英文版本。无论哪种语言，功能和体验完全一致。

## 如何开始使用

### 第一步：启动程序

您有两种启动方式：

1. **推荐方式**：双击 `AURORA.Launcher-双击启动.exe`，程序会静默启动图形界面，无命令行窗口闪现
2. **备用方式**：如果您习惯 PowerShell，也可以在工具目录中执行对应的 `.ps1` 启动脚本

> ⚠️ 注意：请勿直接双击 `.ps1` 文件运行！所有脚本都内置了启动保护，必须通过 EXE 启动器或 GUI 脚本启动。

### 第二步：选择要分析的日志

启动后，您会看到一个精致的图形界面。在界面上您可以：

1. **选择日志类型**：System（系统日志）是默认选择，也是大多数诊断场景的最佳起点。您也可以选择 Application（应用程序日志）来排查软件崩溃问题
2. **设置日期范围**：可以选择"今天"快速诊断当前问题，也可以自定义起始和结束日期来排查历史问题
3. **选择导出模式**：
   - 单日模式：快速分析某一天的问题
   - 日期范围模式：分析一段时期内的问题趋势
4. **选择导出范围**：
   - 仅高危事件：只导出错误和警告级别的事件，速度快，信息密度高
   - 完整导出：导出所有级别的事件（包括信息级），数据更全面
5. **趋势分析**：勾选后可生成事件频率的时序变化报告

### 第三步：查看结果并执行修复

导出和分析完成后：

- **摘要报告**会告诉您系统的整体健康状况、各类事件的统计数据
- 点击"启动智能分析"按钮，AURORA 的智能引擎会对导出的日志进行深度诊断
- 如果发现问题，会列出详细的问题清单和对应的一键修复命令
- 您可以逐个选择要执行的修复操作——低风险的操作会自动执行，高风险的操作会弹出确认窗口让您决定

## 运行环境要求

AURORA 设计时充分考虑了兼容性，力图在各种配置的 Windows 电脑上都能流畅运行：

- **操作系统**：Windows 10、Windows 11、Windows Server 2016 及以上版本
- **PowerShell**：5.1 或更高版本（Windows 10/11 默认已内置）
- **.NET Framework**：4.x（通常系统已预装）
- **内存**：建议 4GB 以上（8GB 以上体验更佳）

对于配置较低的电脑，AURORA 会自动检测硬件性能并降低界面动画效果，确保工具本身不会成为系统负担。

## 常见问题

**Q: 启动时提示"无法验证加密文件"怎么办？**

A: 这说明您可能是直接双击 `.ps1` 文件启动的。请改为双击 `AURORA.Launcher-双击启动.exe` 启动。

**Q: 为什么无法导出 Security 日志？**

A: Security 日志受到 Windows 保护，需要管理员权限才能访问。请在启动 EXE 时右键选择"以管理员身份运行"。

**Q: 导出的文件保存在哪里？**

A: 默认保存在工具目录下的 `UserLogs` 文件夹中。导出完成后会自动打开该文件夹。

**Q: 趋势分析显示什么内容？**

A: 趋势分析会统计选定时间范围内各类事件（严重、错误、警告）的出现频率变化，帮助您判断系统问题是恶化趋势还是已经恢复正常。

**Q: "智能分析"和普通导出有什么区别？**

A: 普通导出是将原始日志转换为可读的报告格式。智能分析则是在此基础上，使用内置的 6 大类诊断规则库对每条高危事件进行深度匹配，给出具体的修复建议和可执行的操作命令。

**Q: 执行修复操作安全吗？**

A: AURORA 为每条命令标注了风险等级。低风险操作（如查询系统温度、查看启动项）会自动执行，高风险操作（如 CHKDSK 磁盘修复）会弹出确认窗口，需要您授权后才会执行。操作失败还会自动回滚。
